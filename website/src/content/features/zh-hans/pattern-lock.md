大多数 App 让你输入数字，Velcrypt 让你画图。图案锁是每个保险箱的大门，也是派生保险箱加密密钥的秘密，所以值得花几分钟好好想一想。

## 5×5 图案锁如何运作

图案锁是一种通过在点与点之间描绘路径（而不是输入密码）来解锁的方式，也就是常说的手势密码。在 Velcrypt 中，网格有 25 个点，排成五行五列。你把手指按下，拖过你选择的点，抬起手指即完成。

每个图案都要遵守两条规则：

1. **至少 6 个点。** 更短的线条会被拒绝。
2. **至少转向一次。** 不允许只画一条直线。

这只是最低要求。Velcrypt 建议使用 **8–12 个点**的图案，因为每多一个点，别人需要尝试的可能图案数量就会成倍增加。

每个图案还不只是用来解锁：它决定打开哪个保险箱。这一思路在[隐藏保险箱](id:hidden-vaults)页面中有详细说明。

## 怎样的图案才算强

强图案应当够长、转向频繁，而且看起来不像任何东西。网格很大，但人们往往重复同样的习惯：从左上角开始、描字母，或画规整的方框。这些习惯恰恰是旁观者或猜测者最先尝试的。

| 习惯 | 为什么弱 | 更好的做法 |
| --- | --- | --- |
| 从角落开始 | 角落是最常见的起点 | 从内部或边缘的点开始 |
| 字母和形状（L、Z、S、U、正方形） | 容易猜到，也容易被人从身后认出 | 使用没有明显形状的不规则路径 |
| 长直线 | 决策少，不确定性低 | 每隔两三个点就换个方向 |
| 只在一个区域内 | 只用到网格的一小部分 | 跨越多行多列 |
| 图案很短 | 需要尝试的组合更少 | 目标 8–12 个点 |

一些实用建议：

- **让路径与自己交叉。** 越过之前线段的线条，更难从屏幕上的指纹痕迹或匆匆一瞥中看出来。
- **让节奏对你顺手，而不是对别人。** 凭手感就能画出的路径，比需要思考的随机路径更容易记住。
- **在依赖它之前先画几遍。** 反复练习才能把新图案变成肌肉记忆。
- **遮挡屏幕。** 如果有人看着你画，再好的图案也没用。在公共场合请侧过手机或遮住网格。

如果你想听听第二意见，[图案强度检测](id:pattern-strength-checker)会根据长度、转向、交叉和网格覆盖范围，给出粗略的评级和比特数估算。这只是一种经验性估算，并非保证；请测试一个与你的图案相似的图案，而不是真实的那个。

## 为什么不支持 Face ID 或 Touch ID

Velcrypt 没有生物识别解锁，这是一个刻意的决定。生物识别之所以方便，正是因为它总是跟着你，而这也是它的弱点：别人可以把手机举到你面前，或者在你不同意的情况下把你的手指按到传感器上。

图案只存在于你的脑海里。没有人能从你的手上取走它，也不能把手机对准你的脸来获取它。对于一个用来保护你最私密文件的保险箱，这种差别比解锁时省下的一秒钟更重要。[图案锁、PIN 码与 Face ID 对比](id:pattern-lock-vs-pin-vs-face-id)更深入地比较了其中的取舍。

## 你的图案与加密密钥

图案并不是验证一下就被丢在一边。Velcrypt 会让它经过一个刻意放慢的密钥派生函数，生成用于解锁保险箱主密钥的密钥，而主密钥又保护着每一个文件。完整的密钥链见[加密](id:encryption)页面。

这带来一个需要坦诚说明的后果。由于图案是密钥的一部分，没有“重置图案”的链接，也没有可以兜底的账户。如果你忘了它，保险箱就会永远锁着。在选择图案之前，请先阅读[忘记保险箱图案怎么办](id:forgot-vault-pattern)，并选一个六个月后你仍然记得的图案。

## 图案无法防范的情况

强图案能提高门槛，但它只是其中一层。它无法阻止有人拍下或看着你画图案，无法阻止你在保险箱打开时把手机交给别人，也无法防范越狱设备上的恶意软件。[安全页面](id:security#what-velcrypt-does-not-protect-against)完整列出了这些限制。把图案与[自动锁定](id:auto-lock)搭配使用，可以堵住最常见的漏洞：放下手机时保险箱仍开着。
