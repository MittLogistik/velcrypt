ビデオは写真以上に個人的なことが多く、カメラロールで同じくらい簡単に人の目に触れてしまいます。Velcryptなら、ビデオを暗号化された保管庫に移してそこで再生でき、もう「写真」アプリを使う必要はありません。

## 動画を取り込む仕組み

ビデオの取り込みは、[写真の取り込み](id:hide-photos)と同じ方法です。iOSのピッカーで1本または複数のビデオを選ぶと、Velcryptは開いている保管庫に暗号化されたコピーを保存します。ビデオ全体を端末上で暗号化してから保存するため、大きなファイルは少し時間がかかります。

写真と同じく、取り込みは**コピー**です。元のビデオは、削除するまで「写真」ライブラリに残ります。そのため、何かを削除する前に、保管庫内でビデオが正しく再生されるかを確認できます。

各ビデオは、保管庫のマスター鍵から導出した個別の鍵を使い、AES-256-GCMで暗号化されます。鍵の仕組みの全体は[暗号化](id:encryption)のページにあります。

## 保管庫の中で再生する

Velcryptにはプレーヤーが内蔵されているため、書き出さずにビデオを見られます。再生は保管庫が開いている間に行われます。アプリを切り替えると、Velcryptは[自動ロック](id:auto-lock)の設定に従ってロックされ、Appスイッチャーには再生していた内容のプレビューが表示されません。

ビデオは関連する写真と同じ[アルバム](id:albums)にまとめ、ビューアでスワイプしながら見ることもできます。

## 元の動画を削除する

隠したビデオがプライベートになるのは、元のビデオが消えてからです。

1. **「写真」を開き、取り込んだビデオを選択します。**
2. **削除します。** ビデオは「最近削除した項目」に移動します。
3. **「最近削除した項目」を開きます。** iOS 18以降では「写真」アプリの「ユーティリティ」の下にあります。それより前のバージョンでは「アルバム」タブの下のほうにあります。
4. **そこからも削除します。** そうしないと、約30日間は復元できる状態のままです。

## ストレージ容量について

ビデオファイルはサイズが大きく、高解像度の映像は数分でも数GBになることがあります。保管庫には元のビデオとほぼ同じ量のデータが保存されます。

次の3点に気をつけてください。

- **一時的に2倍の容量。** 取り込んでから元のビデオを削除するまで、ビデオは2つ存在します。iPhoneの容量が残り少ないときは、何回かに分けて取り込みましょう。
- **「最近削除した項目」も容量を使う。** 削除したビデオは、「最近削除した項目」を空にするか約30日が過ぎるまで、容量を使い続けます。
- **大量に取り込む前に確認する。** 「設定」›「一般」›「iPhoneストレージ」で、空き容量とVelcryptの使用量を確認できます。

| 段階 | 使用する容量 |
| --- | --- |
| 取り込み前 | 元のビデオのみ |
| 取り込み後 | 元のビデオ＋暗号化されたコピー |
| 元のビデオを削除後 | 暗号化されたコピー＋「最近削除した項目」内の項目 |
| 「最近削除した項目」を空にした後 | 暗号化されたコピーのみ |

## 知っておきたいこと

- Velcryptにはカメラ機能が内蔵されていません。「カメラ」アプリで撮影してビデオを取り込み、元のビデオを削除してください。
- パターンが違えば、別の[隠し保管庫](id:hidden-vaults)が開きます。決してほかのビデオと並べたくないものは、別のアルバムではなく専用の保管庫に入れましょう。
- 最初のバージョンでは、保管庫のデータはバックアップされません。かけがえのないビデオは、信頼できる別の場所にもう1つコピーを保管してください。
- チャットで送ったり共有アルバムに投稿したりしたことのあるビデオは、そのコピーが保管庫の外にあります。このリスクについては[プライベートな写真を安全に保管する](id:store-intimate-photos-safely-iphone)ガイドで詳しく扱っています。

標準機能やほかのアプリを含むすべての方法を知りたい場合は、[iPhoneで動画を隠す方法](id:hide-videos-iphone)をご覧ください。
