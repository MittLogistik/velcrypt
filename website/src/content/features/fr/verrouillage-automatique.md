Le plus souvent, des photos privées sont vues non pas à cause d’un piratage, mais d’un téléphone laissé sur une table ou tendu à quelqu’un avec une app encore ouverte. Le verrouillage automatique existe exactement pour ce moment-là : dès que vous quittez Velcrypt, le coffre se referme derrière vous.

## Comment fonctionne le verrouillage automatique

Le verrouillage automatique est une fonction qui ferme le coffre ouvert quand l’app n’est plus au premier plan. Dans Velcrypt, il se déclenche chaque fois que l’app passe en arrière-plan, par exemple quand vous :

- revenez à l’écran d’accueil,
- passez à une autre app,
- répondez à un appel ou ouvrez une notification,
- verrouillez votre iPhone avec le bouton latéral, ou laissez l’écran s’éteindre.

Après le délai choisi, le coffre se verrouille. À la prochaine ouverture de Velcrypt, la [grille de schéma](id:pattern-lock) apparaît et vous devez retracer votre schéma. Comme chaque schéma correspond à son propre [coffre caché](id:hidden-vaults), c’est le schéma tracé qui décide quel coffre s’ouvre ensuite.

## Un délai réglable

Le délai de verrouillage automatique est le temps que Velcrypt attend, une fois passé en arrière-plan, avant de se verrouiller. Vous le réglez dans les réglages de l’app.

| Délai | Idéal pour | Contrepartie |
| --- | --- | --- |
| Immédiat | Confidentialité maximale | Vous retracez votre schéma à chaque retour |
| Délai court | Copier rapidement quelque chose dans une autre app et revenir | Une brève fenêtre où le coffre peut être rouvert sans schéma |
| Délai plus long | Le confort lors de longues sessions | Plus de temps pour que quelqu’un d’autre prenne le téléphone |

Pour la plupart des gens, l’option immédiate ou un délai court est le bon choix. Si vous utilisez surtout Velcrypt seul chez vous, un délai un peu plus long peut sembler plus confortable ; si vous transportez des fichiers sensibles en voyage, gardez-le court.

## Masqué dans le sélecteur d’apps

Quand vous balayez vers le haut pour changer d’app, iOS affiche un instantané de chaque app ouverte. Sans protection, cet instantané pourrait montrer la dernière photo ou le dernier document consulté, même après le verrouillage du coffre.

Velcrypt masque le contenu des coffres dans le sélecteur d’apps. L’aperçu ne révèle pas ce que vous regardiez : quelqu’un qui fait défiler vos apps ouvertes ne le voit pas.

## Pourquoi le verrouillage compte encore plus avec un schéma

Velcrypt n’a volontairement ni Face ID ni Touch ID : rouvrir un coffre verrouillé implique donc toujours de tracer votre schéma. Cela peut sembler contraignant, et il est tentant de choisir un long délai pour l’éviter. Résistez un peu à cette tentation : le schéma ne protège le coffre que tant que celui-ci est verrouillé. Un délai court, associé à un schéma que vous tracez vite et « à la sensation », vous apporte à la fois confidentialité et confort.

## Conseils pratiques

- **Verrouillez avant de prêter le téléphone.** Le verrouillage automatique démarre quand l’app quitte le premier plan, pas quand quelqu’un d’autre prend le téléphone. Si vous devez passer votre iPhone à quelqu’un, quittez d’abord Velcrypt.
- **Montrez une photo, pas toute votre photothèque.** Pour montrer une seule image de votre pellicule, l’Accès guidé d’iOS peut bloquer l’écran sur une seule app. Le guide [montrer une seule photo avec l’Accès guidé](id:guided-access-show-one-photo) explique comment faire.
- **Utilisez aussi un code d’appareil solide.** Le verrouillage automatique protège Velcrypt ; le code de votre appareil protège tout le reste, y compris l’app Photos et son album « Suppressions récentes ».
- **Protégez votre schéma en public.** Verrouiller souvent signifie tracer souvent votre schéma. Détournez l’écran des regards.
- **Pensez aux autres utilisateurs de votre téléphone.** Enfants, partenaires et réparateurs ont tous le téléphone en main à un moment ou un autre. Les cas d’usage [prêter son téléphone à ses enfants](id:sharing-phone-with-kids) et [quand votre partenaire fait défiler votre pellicule](id:partner-scrolling-camera-roll) montrent comment le verrouillage automatique s’intègre dans une configuration plus large.

## Ce que le verrouillage automatique ne peut pas faire

Le verrouillage automatique ferme le coffre quand vous quittez l’app. Il ne peut pas empêcher quelqu’un de regarder par-dessus votre épaule pendant que le coffre est ouvert, de photographier l’écran avec un autre appareil, ou d’utiliser le téléphone pendant que vous êtes encore dans Velcrypt. Ces limites, et d’autres, sont décrites sur la [page sécurité](id:security#what-velcrypt-does-not-protect-against).
