L’app File somiglia molto a un gestore di file del computer, quindi viene naturale aspettarsi le stesse opzioni: clic destro su una cartella, imposti una password, fatto. iOS non funziona così. In File non c’è un blocco per cartella, né un’impostazione nascosta che lo aggiunga. Puoi però bloccare l’app, bloccare i contenuti in un’altra app o spostare i documenti in un posto che abbia un blocco proprio.

## Perché File non ha password per le cartelle

L’app File è un browser per luoghi di archiviazione: **Sul mio iPhone**, **iCloud Drive** e i fornitori di terze parti che hai collegato. Mostra cosa c’è in quei luoghi ma lascia a iOS il controllo degli accessi. La sicurezza dell’iPhone ruota attorno a un unico codice del dispositivo. Mentre il telefono è bloccato, i dati dei file sono cifrati dalla Protezione dati di iOS; una volta sbloccato, l’app File può mostrarli a chiunque tenga in mano il telefono.

Quindi la domanda realistica non è «come metto una password a questa cartella» ma «come impedisco a chi usa il mio telefono sbloccato di aprire questi documenti».

## Opzione 1: bloccare l’app File (iOS 18 e successivi)

iOS 18 ha aggiunto il blocco delle app, che mette una richiesta di autenticazione davanti a un’app ogni volta che si apre.

1. Trova **File** nella schermata Home o nella Libreria app.
2. Tieni premuta l’icona.
3. Scegli **Richiedi Face ID** (la dicitura segue il tuo dispositivo: Touch ID o codice).
4. Conferma.

Ora File chiede Face ID prima di mostrare qualsiasi cosa. Questo protegge tutte le cartelle di File, non solo una: un vantaggio o un fastidio, a seconda di quanto spesso lo usi.

I limiti sono quelli tipici dei blocchi integrati. L’alternativa è il codice del dispositivo, quindi chi lo conosce può aprire File. Il blocco vale inoltre solo per l’app File; le altre app che accedono agli stessi spazi, come le app di archiviazione cloud o le app con cartelle di documenti proprie, non sono interessate. Le app di Apple in genere non si possono spostare nella cartella delle app nascoste, quindi File resta visibile sul dispositivo.

## Opzione 2: una nota protetta

Apple Note può bloccare singole note, cifrarle e proteggerle con una password separata dal codice dell’iPhone. Le note possono contenere documenti scansionati, foto e allegati, quindi una nota protetta può fare da piccola cartella protetta.

1. Imposta una password personalizzata in **Impostazioni › App › Note › Password** (Impostazioni › Note › Password prima di iOS 18), oppure scegli di usare il codice del dispositivo.
2. Crea una nota e aggiungi i contenuti. Il pulsante della fotocamera ti permette di scansionare documenti direttamente nella nota, così un documento cartaceo non tocca mai la libreria di Foto.
3. Tocca **Altro (•••)** › **Blocca**.

## Opzione 3: proteggere i singoli file

Alcuni tipi di file possono avere una password propria:

- **PDF.** Diversi editor PDF e app per ufficio possono salvare un PDF con password. iOS da solo non ha uno strumento generale per farlo.
- **Documenti Office.** Alcune app di produttività supportano le password sui documenti; se puoi impostarne una su iPhone dipende dall’app.
- **Archivi cifrati.** Alcune app di gestione file possono creare archivi protetti da password.

Questi metodi proteggono un file alla volta, e aprirli e chiuderli può lasciare copie decifrate in cartelle temporanee, a seconda dell’app. Sono utili quando devi inviare un file protetto a qualcuno; come archivio quotidiano sono scomodi.

## Opzione 4: una cassaforte cifrata

Un’app cassaforte importa i documenti nel proprio spazio e li cifra con un segreto che conosci solo tu. In pratica è la cartella protetta da password che File non offre, con il vantaggio in più che il blocco non è il codice del dispositivo.

Quando ne scegli una, verifica che cifri davvero i file (e non si limiti a nasconderli), se carica qualcosa online e se può importare dall’app File, visto che lì vive la maggior parte dei documenti. Ricordati di eliminare poi l’originale da File: una copia importata non rimuove la fonte. Se il file era in iCloud Drive, controlla anche **Eliminati di recente** tra le posizioni di Sfoglia nell’app File.

## Dove si accumulano i documenti senza che te ne accorga

Bloccare una cartella serve solo se i file delicati sono davvero lì dentro. Su iPhone i documenti tendono ad accumularsi in pochi posti prevedibili:

- **Download.** Safari e Mail salvano i file in una cartella Download dentro File, in iCloud Drive o in Sul mio iPhone a seconda delle impostazioni di Safari.
- **Allegati di Mail.** Aprire un allegato non lo elimina dall’email. Il messaggio resta nella casella di posta, su ogni dispositivo che la sincronizza.
- **Messaggi e app di chat.** PDF e scansioni inviati o ricevuti restano nella conversazione finché non li elimini lì.
- **Eliminati di recente in File.** I file che elimini da iCloud Drive o da Sul mio iPhone finiscono in una posizione Eliminati di recente nel pannello Sfoglia, dove restano per un po’ prima di essere rimossi per sempre.

## Quale opzione fa per te

| Esigenza | Scelta migliore |
| --- | --- |
| Impedire l’accesso occasionale a tutti i miei file | Bloccare l’app File |
| Proteggere qualche nota o scansione con una password separata | Note protette |
| Inviare un file protetto a qualcuno | PDF o archivio protetto da password |
| Tenere scansioni di documenti d’identità, cartelle cliniche o contratti al riparo da chi conosce il mio codice | Cassaforte cifrata |

Per documenti d’identità e dati sanitari in particolare, il caso d’uso su [documenti medici e d’identità](id:medical-and-id-documents) offre più contesto.

## Dove si inserisce Velcrypt

Velcrypt conserva i [documenti privati](id:private-documents) nelle stesse casseforti cifrate di foto e video. Li importi dall’app File e vengono cifrati sul dispositivo con AES-256-GCM, con chiavi derivate dalla tua sequenza di sblocco. Non c’è nessun account e niente va su un server; la pagina sull’[archiviazione offline senza account](id:offline-no-account) spiega cosa significa in pratica.

Poiché i dati della cassaforte sono esclusi dai backup di iCloud e del computer, crea un backup cifrato in Impostazioni → Backup per ogni documento che non puoi permetterti di perdere e conservalo in un posto di cui ti fidi. Se dimentichi la sequenza, nessuno può aprire la cassaforte, nemmeno Velcrypt.
