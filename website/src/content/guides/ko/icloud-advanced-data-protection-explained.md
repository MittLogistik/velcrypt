대부분의 iCloud 데이터는 암호화되어 있지만, 기본적으로 Apple이 키의 사본을 보관합니다. 덕분에 암호를 잊었을 때 Apple이 도와줄 수 있고, 같은 이유로 법적 강제가 있으면 원칙적으로 읽을 수 있는 데이터를 넘겨줄 수도 있습니다. 고급 데이터 보호는 대부분의 데이터에 대해 이 구조를 바꿉니다. 무엇을 다루는지, 편의성 면에서 무엇을 포기해야 하는지, 어떻게 켜는지 알아봅니다.

## 고급 데이터 보호란

고급 데이터 보호(ADP)는 종단간 암호화를 대부분의 iCloud 데이터 항목으로 확장하는 선택형 iCloud 보안 설정입니다. 종단간 암호화란 신뢰하는 내 기기에만 있는 키로 데이터를 암호화하는 것으로, Apple은 암호화된 데이터를 저장하지만 복호화할 수는 없습니다.

ADP가 없으면 계정은 **표준 데이터 보호**를 사용합니다. iCloud 키체인 암호나 건강 데이터 같은 일부 민감한 항목은 표준 데이터 보호에서도 이미 종단간 암호화됩니다. 사진과 iCloud 백업을 비롯한 나머지는 Apple도 보유한 키로 암호화됩니다.

## ADP가 다루는 것과 다루지 않는 것

Apple은 정확한 목록을 지원 사이트에 공개하며, 이따금 변경됩니다. 이 글을 쓰는 시점 기준으로는 다음과 같습니다.

| 데이터 | 표준 데이터 보호 | ADP 사용 시 |
| --- | --- | --- |
| 사진(‘가려진 항목’, ‘최근 삭제된 항목’ 포함) | Apple이 키 보유 | 종단간 암호화 |
| iCloud 백업(메시지 백업 포함) | Apple이 키 보유 | 종단간 암호화 |
| iCloud Drive | Apple이 키 보유 | 종단간 암호화 |
| 메모 | Apple이 키 보유 | 종단간 암호화 |
| 미리 알림, Safari 책갈피, 음성 메모, 지갑 패스, 단축어, Freeform | Apple이 키 보유 | 종단간 암호화 |
| 암호/키체인, 건강, 스크린 타임 | 종단간 암호화 | 종단간 암호화 |
| iCloud Mail | 표준 | 표준 |
| 연락처 | 표준 | 표준 |
| 캘린더 | 표준 | 표준 |

Mail, 연락처, 캘린더는 Apple 생태계 밖의 이메일·캘린더 시스템과 함께 작동해야 하므로 표준 보호로 남습니다.

알아 둘 점이 몇 가지 더 있습니다.

- **공유 콘텐츠에는 한계가 있습니다.** 사진의 공유 앨범은 포함되지 않으며, ‘링크가 있는 모든 사람’과 공유하거나 다른 사람과 협업하는 항목은 다른 규칙을 따를 수 있습니다. 공유 기능에 의존한다면 Apple의 목록을 확인하세요.
- **일부 메타데이터는 Apple이 읽을 수 있습니다.** 파일 크기, 날짜, 특정 체크섬 같은 정보는 서비스 작동에 필요하므로 종단간 암호화되지 않습니다.
- **웹 접근은 기본으로 꺼집니다.** ADP를 켜면 웹에서 iCloud 데이터에 접근하는 옵션을 켜지 않는 한 iCloud.com이 데이터를 보여 줄 수 없습니다. 이 옵션은 브라우저 세션과 키를 일시적으로 공유합니다.

## 켜기 전 요건

ADP는 대부분의 설정보다 요건이 엄격합니다. 한 번 켜면 다른 누구도 내 데이터를 구해 줄 수 없기 때문입니다.

- Apple 계정에 **이중 인증**이 켜져 있어야 합니다.
- 기기에 **기기 암호**(Mac은 암호)가 설정되어 있어야 합니다.
- 계정에 로그인한 모든 기기가 **최신 소프트웨어**여야 합니다. 업데이트할 수 없는 오래된 기기는 Apple 계정에서 로그아웃해야 합니다.
- **복구 수단**이 있어야 합니다. 다음 중 하나 이상을 설정해야 합니다.
  - **복구 연락처**: Apple 기기를 가진 신뢰하는 사람으로, 복구 코드 생성을 도와줄 수 있습니다.
  - **복구 키**: 적어서 안전하게 보관하는 긴 코드입니다.

직장이나 학교에서 제공하는 관리형 Apple 계정, 자녀 계정 등 일부 계정 유형은 ADP를 사용할 수 없습니다.

## 고급 데이터 보호 켜는 방법

iOS 18과 iOS 26에서 경로는 같습니다. 버전에 따라 이름이 조금 다르게 보이면 iCloud 설정 안의 고급 데이터 보호 항목을 찾으세요.

1. 모든 Apple 기기를 업데이트하거나, 업데이트할 수 없는 기기는 로그아웃합니다.
2. 설정 › [사용자 이름] › 로그인 및 보안에서 이중 인증이 켜져 있는지, 아이폰에 암호가 있는지 확인합니다.
3. 설정 › [사용자 이름] › iCloud로 가서 **고급 데이터 보호**까지 스크롤합니다.
4. **고급 데이터 보호 켜기**를 탭하고 안내에 따라 복구 연락처를 추가하거나 복구 키를 만들거나 둘 다 설정합니다.
5. 기기 암호를 입력해 확인합니다. 아이폰이 백그라운드에서 ADP 활성화를 마칩니다.

## 솔직한 장단점

ADP는 의미 있는 강화이지만, 책임이 나에게 넘어옵니다.

**복구는 내 몫입니다.** Apple 계정 암호를 잊고 모든 신뢰하는 기기에 접근할 수 없게 되면, Apple은 종단간 암호화된 데이터를 복원할 수 없습니다. 복구 연락처나 복구 키가 유일한 방법입니다. 둘 다 잃으면 데이터는 사라집니다.

**일부 편의성이 사라집니다.** 웹 접근에는 매번 명시적인 허용이 필요하고, 오래된 기기는 계정에서 제거해야 할 수 있습니다.

**보호 대상은 휴대폰이 아니라 iCloud입니다.** ADP는 Apple 서버에 데이터가 저장되는 방식을 바꿉니다. 내 아이폰 암호를 알고 휴대폰을 집어 든 사람에 대해서는 아무것도 하지 않습니다. [가려진 항목 앨범은 안전한가요?](id:is-iphone-hidden-album-private)에서 설명하듯, ‘가려진 항목’ 앨범은 여전히 같은 암호로 열립니다.

**다른 곳의 사본은 다루지 않습니다.** 채팅으로 보내거나 공유 앨범에 올린 사진은 ADP로 보호되는 보관함 밖에 있습니다.

## 제공 여부: 영국과 기타 지역

ADP가 모든 곳에서 제공된다는 보장은 없습니다. 2025년 2월 Apple은 영국 정부의 요구 이후 영국 신규 사용자에게 고급 데이터 보호 제공을 중단했고, 기존 영국 사용자도 결국 비활성화해야 할 것이라고 밝혔습니다. 이후에도 상황은 계속 변해 왔으며, 다른 나라가 다른 접근 방식을 취할 수도 있습니다.

iCloud 설정에서 옵션이 보이지 않거나 회색으로 비활성화되어 있다면, 오래된 기사에 의존하지 말고 [Apple 지원](https://support.apple.com/)에서 해당 지역의 현재 상태를 확인하세요.

## 기기 내 암호화의 위치

고급 데이터 보호와 기기 내 금고는 서로 다른 문제를 해결합니다. ADP는 iCloud 데이터를 Apple이 읽을 수 없게 하면서도 동기화하고 내 복구 수단으로 복구할 수 있게 합니다. 기기 내 금고는 특정 파일이 아예 클라우드로 가지 않게 하고, 그 파일과 내 휴대폰 잠금을 해제할 수 있는 사람 사이에 별도의 비밀을 둡니다.

Velcrypt는 두 번째 범주에 속합니다. 가져온 사진, 동영상, 문서는 내가 그리는 패턴에서 파생된 키로 아이폰에서 AES-256-GCM 암호화됩니다([암호화 작동 방식](id:encryption)). 계정이 없고 아무것도 업로드되지 않습니다([기기 내 보관, 계정 없음](id:offline-no-account)). 금고 내용은 iCloud와 컴퓨터 백업에서 완전히 제외되므로, 휴대폰을 잃어버렸을 때 되살릴 수 있는 것은 직접 만들어 둔 Velcrypt 암호화 백업 파일뿐입니다. 이 파일은 내가 정한 백업 암호로 보호됩니다.

많은 사람이 둘 다 현명하게 사용합니다. 일상 보관함과 백업에는 ADP를, 어디에도 동기화되면 안 되는 몇몇 파일에는 금고를 씁니다. 암호화 용어를 따져 보고 있다면 [AES-256 설명](id:aes-256-encryption-explained)과 [숨긴 사진은 iCloud에 저장되나요?](id:are-hidden-photos-saved-to-icloud)를 다음으로 읽어 보세요.
