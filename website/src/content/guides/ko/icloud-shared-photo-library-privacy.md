iCloud 공유 사진 보관함은 Apple이 가족을 위해 만든 기능 중에서도 특히 편리한 기능입니다. 여행, 생일, 학교 행사 사진을 하나의 보관함에 모아 모두가 함께 채워 갈 수 있죠. 하지만 은행 명세서 스크린샷이나 사적인 사진이 나도 모르게 배우자, 부모님, 사춘기 자녀 앞에 놓일 수 있는 곳이기도 합니다. 이 가이드에서는 다른 참여자가 정확히 무엇을 보고 무엇을 할 수 있는지, 내가 아무것도 누르지 않아도 사진이 들어가는 방식, 그리고 공유하고 싶지 않은 사진을 빼 두는 방법을 설명합니다.

## iCloud 공유 사진 보관함이란

공유 보관함은 사진 앱에서 **개인 보관함**과 나란히 있는 두 번째 사진 보관함입니다. Apple이 설명하는 기본 사항은 다음과 같습니다.

- iOS 16.1, iPadOS 16.1 또는 macOS Ventura 이상이 필요하며, iCloud 사진이 켜져 있어야 합니다.
- 보관함을 만든 대표를 포함해 최대 6명이 참여할 수 있습니다. 한 번에 하나의 공유 보관함에만 참여할 수 있습니다.
- 모든 콘텐츠는 대표의 iCloud 저장 공간을 사용하며, 다른 참여자의 저장 공간은 사용하지 않습니다.
- 사진을 추가하면 개인 보관함에서 공유 보관함으로 **이동**합니다. 복사본이 아닙니다.
- 만들 때 가족 공유는 필요하지 않습니다. 만 13세 미만(나이는 국가나 지역마다 다름)은 가족 공유 그룹 구성원하고만 공유 보관함을 만들거나 참여할 수 있습니다.

## 다른 참여자가 볼 수 있는 것과 할 수 있는 것

대부분의 사람이 가장 과소평가하는 부분입니다. 공유 보관함은 누구에게도 '보기 전용'이 아닙니다. Apple은 모든 참여자가 콘텐츠를 추가, 편집, 삭제할 수 있다고 설명합니다.

| 공유 보관함 항목에 대한 작업 | 모든 참여자 | 추가한 본인만 | 대표만 |
| --- | --- | --- | --- |
| 사진이나 비디오 보기(날짜, 위치, 캡션 포함) | 가능 | | |
| 편집, 자르기, 즐겨찾기, 캡션이나 날짜 변경 | 가능(모두에게 반영됨) | | |
| 삭제(최근 삭제된 항목으로 이동) | 가능 | | |
| 최근 삭제된 항목에서 완전히 삭제 | | 가능 | |
| 개인 보관함으로 되돌리기 | | 가능 | |
| 참여자 추가·제거, 보관함 삭제 | | | 가능 |

공유 보관함의 콘텐츠는 모든 참여자의 추억, 추천 사진, 사진 위젯에도 나타납니다. 내가 옮긴 사진이 다른 사람이 찾지도 않았는데 그 사람의 홈 화면에 뜰 수 있다는 뜻입니다.

반대로 참여자에게 **보이지 않는** 것은 내 개인 보관함입니다. 가족 iPad에서 내 사적인 사진이 보인다면, 원인은 보통 공유 보관함이 아니라 내 Apple 계정으로 로그인된 기기입니다. 이 경우는 [가족 iPad에 내 사진이 보이는 이유](id:family-shared-icloud)에서 정리했습니다.

## 사진이 공유 보관함에 들어가는 경로

경로는 다섯 가지이며, 사진을 하나하나 의식해서 고르는 것은 첫 번째뿐입니다.

1. **직접 이동.** 사진 앱에서 사진을 선택하고 더 보기 버튼(•••)을 탭한 다음 **공유 보관함으로 이동**을 선택합니다. 설정 과정에서 예전 사진을 한꺼번에 옮길 수도 있습니다.
2. **카메라의 공유 보관함 버튼.** 참여하면 카메라 화면 상단에 공유 보관함 버튼이 나타납니다. 켜져 있으면 새 사진과 비디오가 바로 공유 보관함에 저장되고, 꺼져 있으면 개인 보관함에 저장됩니다.
3. **자동으로 공유.** 이 옵션을 선택하면 다른 참여자 근처에 있을 때 찍은 사진이 자동으로 공유 보관함에 추가됩니다. 근처에 있는지 감지하려면 참여자가 Apple 계정에 로그인되어 있고 Bluetooth가 켜져 있어야 합니다.
4. **집에 있을 때 공유.** 집에서 찍은 사진과 비디오가 자동으로 공유 보관함에 추가됩니다.
5. **제안.** 참여자가 근처에 있을 때 찍은 사진이나 설정할 때 고른 사람이 나온 사진처럼 추가할 만한 사진을 사진 앱이 제안하고, 검토하라는 알림을 보냅니다. 제안은 **공유 보관함을 위한 제안**에 표시됩니다. 승인하기 전에는 아무것도 이동하지 않지만, 하나하나 확인하지 않고 한꺼번에 승인하기 쉽습니다.

## 개인 사진을 빼 두는 방법

공유 보관함에서 나가지 않아도 설정만으로 관리할 수 있습니다.

1. **설정 › 앱 › 사진 › 공유 보관함**으로 이동합니다(iOS 17 이하에서는 **설정 › 사진 › 공유 보관함**). 사진 앱에서도 모음, 오른쪽 상단의 계정, 공유 보관함 순으로 탭하면 같은 화면이 나옵니다.
2. **카메라에서 공유**를 탭합니다. **수동으로 공유**를 선택하면 내가 직접 켰을 때만 카메라가 공유 보관함에 저장합니다. 카메라에서 공유를 아예 꺼도 됩니다. **집에 있을 때 공유**도 꺼져 있는지 확인하세요.
3. 더 공유하라는 알림이 필요 없다면 **공유 보관함 제안**을 끕니다.
4. 사적인 사진을 찍기 전에 카메라의 공유 보관함 버튼이 꺼져 있는지 확인합니다.
5. 이미 공유된 항목을 확인합니다. 사진 앱의 보기를 **공유 보관함**으로 바꾸면 공유된 항목만 보이고, '두 보관함 모두' 보기에서는 공유된 항목의 썸네일 모서리에 작은 아이콘이 붙습니다. 이 보기 옵션의 위치는 iOS 버전마다 바뀌었으며, iOS 26에서는 '보관함'을 탭한 다음 정렬 및 필터 버튼을 탭합니다.

## 사진을 개인 보관함으로 되돌리기

공유 보관함의 사진이나 비디오를 열고 더 보기 버튼(•••)을 탭한 다음 **개인 보관함으로 이동**을 선택합니다. 먼저 여러 항목을 선택해도 됩니다. 이동한 뒤에는 다른 참여자에게 더 이상 보이지 않습니다.

중요한 제한이 두 가지 있습니다. 첫째, **내가** 추가한 항목만 옮길 수 있습니다. 다른 사람이 추가한 내 사진은 그 사람이 옮기거나 삭제하기 전까지 공유 보관함에 남습니다. 둘째, 되돌린다고 해서 지난 일이 사라지지는 않습니다. 공유되어 있던 동안 누군가 저장하거나, 메시지로 보내거나, 내보냈을 수 있습니다. 공유 보관함에 한 번이라도 들어간 것은 이미 누군가 봤다고 생각하세요.

## 가려진 사진과 공유 보관함

사진을 가린다고 공유 보관함 안에서 비공개가 되지는 않습니다. Apple에 따르면 공유 보관함에 있는 사진을 가리면 그 사진은 **모든 참여자의** 가려진 항목 앨범으로 이동하고, 다른 참여자도 보거나 가리기를 해제할 수 있습니다. 가려진 항목 앨범은 기본적으로 Face ID, Touch ID 또는 암호로 잠겨 있지만, 각 참여자는 자기 기기로 잠금을 해제합니다. 내 잠금이 아닙니다.

안전한 순서는 먼저 개인 보관함으로 옮긴 다음 가리는 것입니다. 참고로 개인 보관함의 가려진 사진도 내 Apple 계정으로 로그인된 모든 기기에 동기화됩니다. 자세한 내용은 [가려진 사진도 iCloud에 저장될까?](id:are-hidden-photos-saved-to-icloud)를 참고하세요.

## 공유 보관함에서 나가기 또는 삭제하기

사진 앱에서 모음을 탭하고, 오른쪽 상단의 계정을 탭한 다음 **관리**를 탭합니다.

- **공유 보관함에서 나가기**(참여자): 공유 보관함의 모든 콘텐츠를 개인 보관함으로 복사할지, 내가 추가한 것만 받을지 선택합니다.
- **공유 보관함 삭제**(대표만): 모든 참여자에게 알림이 갑니다. 7일 이상 참여한 사람은 모든 콘텐츠를 복사할 수 있고, 참여한 지 7일 미만인 사람은 자신이 추가한 것만 받습니다.

대표는 특정 참여자만 제거할 수도 있습니다. 다만 나가는 것으로 보호되는 것은 앞으로의 사진이지 지난 사진이 아닙니다. 다른 참여자는 내가 공유한 모든 것의 복사본을 계속 가질 수 있습니다.

| 어떤 기능인가 | 최대 6명이 쓰는 두 번째 전체 보관함 | 고른 사람과 공유하는 개별 앨범 | 구입 항목, 구독, iCloud+ 저장 공간을 나누는 그룹 |
| 사진을 자동으로 공유하나 | 카메라와 집에서 자동 공유될 수 있음 | 아니요, 직접 추가 | 아니요 |
| 편집·삭제할 수 있는 사람 | 모든 참여자 | 소유자(허용하면 구독자도 추가 가능) | 해당 없음 |
| 고급 데이터 보호 시 종단 간 암호화 | 모든 참여자가 켜면 적용 | 적용 안 됨 | 각자의 개인 보관함은 본인 설정을 따름 |

## 암호화는 어떻게 되나요?

iCloud 사진은 암호화되어 있지만, 기본값인 표준 데이터 보호에서는 Apple이 키를 보관합니다. 고급 데이터 보호를 켜면, Apple 설명에 따르면 공유 콘텐츠는 **모든 참여자가** 고급 데이터 보호를 켜 둔 동안에만 종단 간 암호화가 유지됩니다. 켜지 않은 가족이 한 명만 있어도 공유 보관함은 그 보호를 잃습니다. 공유 앨범은 아예 대상이 아닙니다. 켜는 방법과 주의할 점은 [iCloud 고급 데이터 보호란 무엇인가요?](id:icloud-advanced-data-protection-explained)에서 설명합니다.

'가족 사진 암호화'를 찾고 있다면 솔직한 답은 이렇습니다. Apple 안에서 가장 가까운 방법은 모든 참여자가 고급 데이터 보호를 켠 공유 보관함입니다. 암호화는 Apple 서버에 있는 사진을 보호할 뿐, 원래 그 사진을 보라고 참여한 다른 다섯 명으로부터 지켜 주지는 않습니다.

## 별도의 암호화 금고가 필요한 경우

공유 보관함은 공유하기 위한 기능입니다. 절대 공유하고 싶지 않은 사진은 사진 앱의 보관함에서 완전히 빼 두는 편이 확실합니다.

Velcrypt는 바로 그런 용도의 iPhone 금고 앱입니다. 가져온 사진, 비디오, 문서는 iPhone에서 AES-256-GCM으로 암호화되며, 기기 암호나 Face ID가 아니라 5×5 격자에 그리는 패턴으로 엽니다. [계정도, 서버도, 동기화도 없고](id:offline-no-account), 금고 데이터는 iCloud 백업과 컴퓨터 백업에서 제외되므로 금고 안의 항목이 공유 보관함, 공유 앨범, 가족 iPad에 나타날 일이 없습니다. 패턴마다 별도의 금고가 열리기 때문에 보여 줘도 괜찮은 위장 금고를 따로 둘 수도 있습니다.

가져오기를 하면 암호화된 복사본이 만들어지고 원본은 그대로 남습니다. 가져온 뒤 사진 앱에서 원본을 삭제하고 최근 삭제된 항목도 비우세요. 사진이 공유 보관함에 있었다면 먼저 개인 보관함으로 옮기거나 거기서 삭제하고, 최근 삭제된 항목에서 완전히 삭제할 수 있는 사람은 추가한 본인뿐이라는 점도 기억하세요.

솔직한 단점도 있습니다. 금고는 공유용이 아니고, 내 iPhone에만 존재하며, 패턴을 잊어버리면 복구할 수 없습니다. iPhone 분실에 대비하려면 설정 → 백업에서 암호화된 백업 파일을 만들어 안전한 곳에 보관하세요. 금고에서 사진을 내보내면 암호화되지 않은 일반 복사본이 다시 생깁니다.

## 빠른 체크리스트

- '카메라에서 공유'를 '수동으로 공유'로 바꾸거나 끕니다.
- 필요 없다면 '집에 있을 때 공유'와 '공유 보관함 제안'을 끕니다.
- 사적인 사진을 찍기 전에 카메라의 공유 보관함 버튼을 확인합니다.
- 개인적인 항목은 '개인 보관함으로 이동'으로 되돌린 다음 가리거나 금고로 옮깁니다.
- 공유 보관함에 들어 있는 사진을 가리는 것으로 안심하지 않습니다.
- 절대 공유하면 안 되는 것은 사진 앱 밖, 기기 안의 암호화 금고에 보관합니다.
