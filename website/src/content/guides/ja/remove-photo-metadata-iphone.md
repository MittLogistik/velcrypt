iPhoneで撮るすべての写真には、目に見えない小さな情報が付いています。たいていは便利なものです。「写真」アプリは場所や日付で写真を整理できます。でも、見知らぬ人やフリマアプリの購入者、インターネットに写真を共有すると、自宅の場所まで含めて、意図した以上のことが伝わってしまう可能性があります。

## EXIFメタデータに含まれるもの

EXIF（Exchangeable Image File Format）とは、画像ファイルの中にピクセルと一緒に情報を保存するための規格です。iPhoneの写真には、次のような情報が含まれることがあります。

| 項目 | 例 | 問題になる理由 |
|---|---|---|
| GPS座標 | 緯度と経度。数メートルの精度のことも多い | 自宅、職場、子どもの学校がわかってしまう |
| 日時 | シャッターを切った瞬間 | 生活パターンや、いつどこにいたかがわかる |
| デバイス | メーカーと機種 | 撮影者を絞り込める |
| レンズと設定 | 前面・背面カメラ、焦点距離、露出 | 小さな情報だが、特定の手がかりが増える |
| ソフトウェア | iOSのバージョンや編集アプリ | どのデバイスやアプリで処理したかがわかる |
| 向き | 回転のフラグ | 無害だが、正しく表示するために必要 |

写真にはXMPやIPTCのデータ（キャプション、編集履歴、キーワード）が含まれることもあります。iPhoneの標準形式であるHEICにも、同様の情報が保存されます。

## iPhoneでメタデータを管理する4つの方法

### 1. 共有するときに位置情報を外す

最も身につけやすい習慣で、共有するたびに設定できます。

1. 「写真」で1枚以上の写真を選び、**共有**をタップします。
2. 共有シートの上部、選択内容の表示の下にある**オプション**をタップします。
3. **位置情報**をオフにします。iOSのバージョンによっては、キャプションなどほかの写真データや、オリジナルのファイルとして送るためのオプションも表示されます。
4. **完了**をタップし、いつもどおり共有します。

この設定はその共有にだけ適用され、元の写真の位置情報は残ります。メッセージ、メール、AirDrop、そして共有シートで写真を受け取るほとんどのアプリで使えます。

### 2. 写真そのものから位置情報を削除する

ライブラリの写真から位置情報を消したい場合は、次のようにします。

1. 「写真」で写真を開きます。
2. 上にスワイプするか、**情報**（ⓘ）ボタンをタップします。
3. 位置情報または地図の横にある**調整**をタップします。
4. **位置情報なし**を選びます。

最近のiOSでは、複数の写真を選んでまとめて位置情報を調整できます。表示はiOS 18とiOS 26で多少異なる場合があるので、情報パネルの位置情報の欄を探してください。

### 3. カメラが位置情報を記録しないようにする

新しい写真にGPS情報をまったく保存しないようにするには、次のようにします。

1. **「設定」›「プライバシーとセキュリティ」›「位置情報サービス」**を開きます。
2. **カメラ**をタップします。
3. **しない**を選びます。

### 4. それ以外はメタデータ削除ツールで

共有シートで扱えるのは主に位置情報です。日時、機種、そのほかの埋め込みデータも消したいなら、専用のツールを使いましょう。当サイトの[写真メタデータ削除ツール](id:photo-metadata-remover)はすべてブラウザ内で動作し、何もアップロードされません。JPEGに含まれる情報（カメラ、レンズ、日時、ソフトウェア、向き、GPS座標）を表示し、ピクセルを描き直して新しいJPEGとして保存することで、EXIF、GPS、XMP、IPTC、そのほかの埋め込みメタデータを取り除きます。

いくつか知っておいてください。再エンコードによってファイルサイズがわずかに変わることがあります。HEICは、Safariなどブラウザが開ける場合にだけ使えます。また、iPhoneのSafariで写真を選ぶと、iOSがすでにHEICをJPEGに変換している場合があります。

## スクリーンショットの裏技と、その大ざっぱさ

よく紹介されるのが、写真のスクリーンショットを撮ってそれを共有する方法です。スクリーンショットはまったく新しい画像なので、元の写真のGPS座標は含まれません。ただし、

- 元の写真より解像度が低く、おかしな形に切り取られることもある
- ステータスバー、通知など、画面のほかの部分が写り込むことがある
- 撮影日時やデバイスなど、独自のメタデータを持っている
- うっかりオリジナルのほうを共有してしまいやすい

という欠点があります。急ぎのときには使えますが、大切な場面では共有シートのオプションかメタデータ削除ツールを使いましょう。

## メタデータは取り消せない

メタデータを削除して変わるのは、編集しているコピーだけです。すでにオリジナルを投稿、送信、アップロードしていれば、相手のコピーには元のデータがそのまま残ります。アップロード時にメタデータを消すプラットフォームもありますが、多くのメッセージやファイル共有の経路では消えません。過去に共有したものは、元のデータを含んだままだと考えてください。

メタデータではないものにも注意が必要です。顔、番地の表示、ナンバープレート、店の看板、特徴的な景色、窓に映った反射は、GPSと同じくらい正確に場所を特定できます。

## メタデータを読めるアプリは？

写真へのフルアクセスを許可したアプリは、位置情報を含め、ライブラリのすべての写真のメタデータを読めます。アプリへの許可を選択した写真だけに制限すれば、その範囲を減らせます。iOSの写真へのアクセス許可の仕組みは、[写真にアクセスできるアプリの確認方法](id:which-apps-can-see-your-photos-iphone)をご覧ください。

## Velcryptの位置づけ

Velcryptは写真を編集したりメタデータを削除したりはせず、写真を守ります。保管庫に読み込んだ写真はiPhone上でAES-256-GCMにより暗号化されるため、埋め込まれたメタデータを含む中身を、ほかのアプリやライブラリを見ている人が読むことはできません。プライベートな写真を持っているなら、2つの習慣を組み合わせるのが効果的です。共有する前に位置情報を外し、オリジナルは暗号化保管庫に保管しましょう。[iPhoneで写真を隠す方法](id:hide-photos-iphone)と[プライベートな写真を安全に保管する方法](id:store-intimate-photos-safely-iphone)もご覧ください。
