iCloudのデータの大部分は暗号化されていますが、初期設定ではAppleが鍵のコピーを保持しています。だからこそ、パスワードを忘れたときにAppleが手助けでき、同時に、法的に強制された場合には原理的に読める状態のデータを提出できてしまいます。「高度なデータ保護」は、データの大部分についてこの仕組みを変えます。何が対象になり、どんな利便性を手放すことになり、どうオンにするのかを説明します。

## 「高度なデータ保護」とは

「高度なデータ保護」（ADP）とは、エンドツーエンド暗号化をiCloudのほとんどのデータカテゴリーに広げる、オプトイン型のiCloudのセキュリティ設定です。エンドツーエンド暗号化とは、あなたの信頼できるデバイスにしか存在しない鍵でデータを暗号化する方式で、Appleは暗号化されたデータを保存しますが、復号はできません。

ADPを使わない場合、アカウントは**標準のデータ保護**になります。iCloudキーチェーンのパスワードやヘルスケアのデータなど、一部の機密性の高いカテゴリーは標準のデータ保護でもすでにエンドツーエンドで暗号化されています。写真やiCloudバックアップなどそれ以外のカテゴリーは、Appleも保持する鍵で暗号化されています。

## ADPの対象になるもの・ならないもの

Appleは正確な一覧をサポートサイトで公開しており、内容はときどき変わります。執筆時点では次のとおりです。

| データ | 標準のデータ保護 | ADPあり |
| --- | --- | --- |
| 写真（「非表示」と「最近削除した項目」を含む） | Appleが鍵を保持 | エンドツーエンド暗号化 |
| iCloudバックアップ（メッセージのバックアップを含む） | Appleが鍵を保持 | エンドツーエンド暗号化 |
| iCloud Drive | Appleが鍵を保持 | エンドツーエンド暗号化 |
| メモ | Appleが鍵を保持 | エンドツーエンド暗号化 |
| リマインダー、Safariのブックマーク、ボイスメモ、Walletのパス、ショートカット、フリーボード | Appleが鍵を保持 | エンドツーエンド暗号化 |
| パスワード／キーチェーン、ヘルスケア、スクリーンタイム | エンドツーエンド暗号化 | エンドツーエンド暗号化 |
| iCloudメール | 標準 | 標準 |
| 連絡先 | 標準 | 標準 |
| カレンダー | 標準 | 標準 |

メール、連絡先、カレンダーが標準の保護のままなのは、Appleのエコシステムの外にある幅広いメールやカレンダーのシステムと連携する必要があるからです。

ほかにも知っておきたい点があります。

- **共有したコンテンツには限界がある。**「写真」の共有アルバムは対象外で、「リンクを知っている全員」と共有した項目や、ほかの人と共同作業している項目には別のルールが適用されることがあります。共有に頼っているなら、Appleの一覧を確認しましょう。
- **一部のメタデータはAppleが読める。**ファイルサイズ、日付、特定のチェックサムなどはサービスの動作に必要なため、エンドツーエンドで暗号化されません。
- **Webアクセスは初期設定でオフ。**ADPがオンの場合、iCloudデータにWebでアクセスするオプションを有効にしない限り、iCloud.comにはデータが表示されません。有効にすると、ブラウザのセッションと一時的に鍵が共有されます。

## オンにする前の条件

ADPはほかの多くの設定より条件が厳しくなっています。一度オンにすると、ほかの誰もあなたのデータを救えないからです。

- Apple Accountで**2ファクタ認証**が有効になっていること。
- デバイスに**デバイスのパスコード**（Macではパスワード）が設定されていること。
- アカウントにサインインしているすべてのデバイスの**ソフトウェアが最新**であること。古いデバイスをアップデートできない場合は、そのデバイスをApple Accountからサインアウトする必要があります。
- **復旧手段**。次のうち少なくとも1つを設定する必要があります。
  - **復旧用連絡先**：Appleデバイスを持つ信頼できる人で、あなたのために復旧コードの生成を手伝ってくれます。
  - **復旧キー**：書き留めて安全に保管する長いコードです。

勤務先や学校が提供する管理対象Apple Accountや、子ども用アカウントなど、一部のアカウントの種類ではADPを使えません。

## 「高度なデータ保護」をオンにする方法

iOS 18とiOS 26では手順は同じです。お使いのバージョンで表記が少し違う場合は、iCloudの設定の中で「高度なデータ保護」の項目を探してください。

1. すべてのAppleデバイスをアップデートするか、アップデートできないデバイスからサインアウトします。
2. 「設定」›［ユーザ名］›「サインインとセキュリティ」で2ファクタ認証がオンになっていること、iPhoneにパスコードが設定されていることを確認します。
3. 「設定」›［ユーザ名］›「iCloud」を開き、**高度なデータ保護**までスクロールします。
4. **高度なデータ保護をオンにする**をタップし、画面の指示に従って復旧用連絡先の追加、復旧キーの作成、またはその両方を行います。
5. デバイスのパスコードを入力して確定します。iPhoneはバックグラウンドでADPの有効化を完了します。

## 正直なトレードオフ

ADPは意味のある強化ですが、責任をあなたに移します。

**復旧はあなたの仕事になる。**Apple Accountのパスワードを忘れ、すべての信頼できるデバイスにアクセスできなくなると、Appleはエンドツーエンドで暗号化されたデータを復元できません。戻る道は復旧用連絡先か復旧キーだけです。両方を失えば、データは失われます。

**一部の利便性がなくなる。**Webアクセスには毎回明示的な許可が必要になり、古いデバイスはアカウントから削除しなければならない場合があります。

**守るのはiCloudで、iPhoneではない。**ADPが変えるのは、Appleのサーバーでのデータの保存方法です。iPhoneのパスコードを知っている人がiPhoneを手に取った場合には、何の効果もありません。「非表示」アルバムは相変わらず同じパスコードで開きます。詳しくは[「非表示」アルバムは本当に安全か](id:is-iphone-hidden-album-private)で説明しています。

**ほかの場所のコピーは対象外。**チャットで送った写真や共有アルバムに投稿した写真は、ADPで守られたライブラリの外にあります。

## 利用可否：イギリスとその他の地域

ADPはどこでも利用できるとは限りません。2025年2月、Appleはイギリス政府からの要求を受けて、イギリスの新規ユーザーへの「高度なデータ保護」の提供を停止し、既存のイギリスのユーザーもいずれ無効にする必要があると発表しました。状況はその後も変化しており、ほかの国が異なる対応をとる可能性もあります。

iCloudの設定にオプションが表示されない、またはグレー表示になっている場合は、古い記事に頼らず、[Appleサポート](https://support.apple.com/)でお住まいの地域の最新の状況を確認してください。

## デバイス上での暗号化の位置づけ

「高度なデータ保護」とデバイス上の保管庫は、別々の問題を解決します。ADPはiCloudのデータをAppleに読めない状態に保ちつつ、同期や、自分の復旧手段による復旧を可能にします。デバイス上の保管庫は、特定のファイルをそもそもクラウドに送らず、iPhoneのロックを解除できる人との間に別の秘密情報を置きます。

Velcryptは後者です。読み込んだ写真、動画、書類はiPhone上でAES-256-GCMにより暗号化され、鍵はあなたが描くパターンから導出されます（[暗号化の仕組み](id:encryption)）。アカウントはなく、何もアップロードされません（[デバイス上で完結、アカウント不要](id:offline-no-account)）。最初のバージョンでは保管庫の中身はiCloudやコンピュータのバックアップから完全に除外されるため、iPhoneを紛失すると復元できるものはありません。暗号化バックアップのオプションは予定されています。

両方を使い分けるのも賢い方法です。日常のライブラリとバックアップにはADPを、どこにも同期すべきでない一部のファイルには保管庫を使います。暗号化の用語を整理したいなら、[AES-256の解説](id:aes-256-encryption-explained)と[非表示の写真はiCloudに保存されるのか](id:are-hidden-photos-saved-to-icloud)も参考になります。
