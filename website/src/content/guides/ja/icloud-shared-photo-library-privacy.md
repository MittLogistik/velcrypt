iCloud共有写真ライブラリは、家族向けにAppleが用意した便利な機能です。旅行や誕生日、運動会の写真を1つのライブラリにまとめ、みんなで追加していけます。一方で、銀行の明細のスクリーンショットやプライベートな写真が、気づかないうちにパートナーや親、思春期の子どもの目に触れてしまう場所でもあります。「iCloudの写真が家族に見られるのでは？」と不安な人に向けて、このガイドでは、ほかの参加者に何が見えて何ができるのか、操作しなくても写真が入ってしまう仕組み、そして見られたくない写真を外しておく方法を説明します。

## iCloud共有写真ライブラリとは

共有ライブラリは、「写真」アプリの**個人用ライブラリ**とは別にある、もう1つの写真ライブラリです。Appleによる基本は次のとおりです。

- iOS 16.1、iPadOS 16.1、macOS Ventura以降が必要で、iCloud写真をオンにしておく必要があります。
- 参加できるのは、作成した管理者を含めて最大6人です。同時に参加できる共有ライブラリは1つだけです。
- すべてのコンテンツは管理者のiCloudストレージを使い、ほかの参加者のストレージは消費しません。
- 写真を追加すると、個人用ライブラリから共有ライブラリへ**移動**します。コピーではありません。
- 作成にファミリー共有は不要です。13歳未満（年齢は国や地域によって異なります）は、ファミリー共有グループのメンバーとだけ共有ライブラリを作成・参加できます。

## ほかの参加者に見えること・できること

多くの人が見落としているのがここです。共有ライブラリは誰にとっても「閲覧のみ」ではありません。Appleは、すべての参加者がコンテンツを追加、編集、削除できると説明しています。

| 共有ライブラリの項目に対する操作 | 参加者全員 | 追加した本人だけ | 管理者だけ |
| --- | --- | --- | --- |
| 写真やビデオを見る（日付、場所、キャプションも含む） | できる | | |
| 編集、切り取り、お気に入り、キャプションや日付の変更 | できる（変更は全員に反映） | | |
| 削除する（「最近削除した項目」へ移動） | できる | | |
| 「最近削除した項目」から完全に削除する | | できる | |
| 個人用ライブラリに戻す | | できる | |
| 参加者の追加・削除、ライブラリの削除 | | | できる |

共有ライブラリのコンテンツは、参加者全員の「メモリー」やおすすめの写真、「写真」ウィジェットにも表示されます。あなたが移動した写真が、ほかの人が探してもいないのにホーム画面に出てくることもあるわけです。

一方、参加者に**見えない**のがあなたの個人用ライブラリです。家族のiPadで自分のプライベートな写真が見られてしまうなら、原因はたいてい共有ライブラリではなく、あなたのApple Accountでサインインしたデバイスです。その場合は[家族のiPadに写真が表示される原因](id:family-shared-icloud)をご覧ください。

## 写真が共有ライブラリに入る経路

経路は5つあり、写真を1枚ずつ意識して選ぶのは1つ目だけです。

1. **手動で移動する。** 「写真」で写真を選び、その他ボタン（•••）をタップして**共有ライブラリに移動**を選びます。設定時に過去の写真をまとめて移動することもできます。
2. **カメラの共有ライブラリボタン。** 参加すると、カメラの画面上部に共有ライブラリボタンが表示されます。オンなら新しい写真やビデオは共有ライブラリに直接保存され、オフなら個人用ライブラリに保存されます。
3. **自動的に共有。** このオプションでは、ほかの参加者の近くにいるときに撮った写真が自動で共有ライブラリに追加されます。近くにいることを検出するには、参加者がApple Accountにサインインし、Bluetoothをオンにしている必要があります。
4. **在宅時に共有。** 自宅で撮った写真やビデオが自動で共有ライブラリに追加されます。
5. **提案。** 参加者が近くにいたときの写真や、設定時に選んだ人が写っている写真など、追加したくなりそうな写真を「写真」が提案し、確認を促す通知を送ります。提案は**共有ライブラリの提案**に表示されます。承認するまで移動はされませんが、1枚ずつ確かめずにまとめて承認してしまいがちです。

## 見られたくない写真を外しておく方法

共有ライブラリを抜けなくても、設定を変えればコントロールできます。

1. **「設定」›「アプリ」›「写真」›「共有ライブラリ」**を開きます（iOS 17以前は**「設定」›「写真」›「共有ライブラリ」**）。「写真」アプリでも、「コレクション」→右上のアカウント→「共有ライブラリ」で同じ画面に行けます。
2. **カメラから共有**をタップします。**手動で共有**を選べば、自分でオンにしたときだけカメラが共有ライブラリに保存します。「カメラから共有」自体をオフにしてもかまいません。**在宅時に共有**がオフになっていることも確認しましょう。
3. 共有をうながす通知が不要なら、**共有ライブラリの提案**をオフにします。
4. プライベートな写真を撮る前に、カメラの共有ライブラリボタンがオフになっているか確かめます。
5. すでに共有されているものを確認します。「写真」の表示を**共有ライブラリ**に切り替えると共有中の項目だけが表示され、「両方のライブラリ」の表示では共有中の項目のサムネールの隅に小さなアイコンが付きます。この表示オプションの場所はiOSのバージョンで変わっており、iOS 26では「ライブラリ」をタップしてから並べ替えとフィルタボタンをタップします。

## 写真を個人用ライブラリに戻す

共有ライブラリの写真やビデオを開き、その他ボタン（•••）をタップして**個人用ライブラリに移動**を選びます。先に複数の項目を選択しておくこともできます。移動後は、ほかの参加者には見えなくなります。

注意点が2つあります。まず、移動できるのは**自分が**追加した項目だけです。ほかの人が追加したあなたの写真は、その人が移動か削除をしない限り共有ライブラリに残ります。次に、戻しても過去はなかったことになりません。共有されていた間に、誰かが保存したり、「メッセージ」で送ったり、書き出したりしているかもしれません。共有ライブラリに一度入ったものは、見られたものと考えてください。

## 非表示の写真と共有ライブラリ

非表示にしても、共有ライブラリの中で写真をプライベートにすることはできません。Appleによると、共有ライブラリにある写真を非表示にすると、その写真は**参加者全員の**「非表示」アルバムに移り、ほかの参加者も表示したり非表示を解除したりできます。「非表示」アルバムは初期設定でFace ID、Touch ID、パスコードでロックされていますが、各参加者は自分のデバイスでロックを解除します。あなたのロックではありません。

安全な順番は、まず個人用ライブラリに移動し、そのあと非表示にすることです。なお、個人用ライブラリの非表示の写真も、あなたのApple Accountでサインインしているすべてのデバイスに同期されます。詳しくは[非表示にした写真はiCloudに保存される？](id:are-hidden-photos-saved-to-icloud)をご覧ください。

## 共有ライブラリから退出する・削除する

「写真」で「コレクション」をタップし、右上のアカウント、**管理**の順にタップします。

- **共有ライブラリから退出**（参加者）：共有ライブラリのすべてを個人用ライブラリにコピーするか、自分が追加したものだけにするかを選べます。
- **共有ライブラリを削除**（管理者のみ）：参加者全員に通知が届きます。参加から7日以上の人はすべてをコピーでき、7日未満の人は自分が追加したものだけを受け取ります。

管理者は特定の参加者だけを削除することもできます。ただし、退出して守れるのはこれからの写真で、過去の写真ではありません。ほかの参加者は、あなたが共有したものすべてのコピーを持ち続けられます。

## 共有ライブラリ、共有アルバム、ファミリー共有の違い

「iCloudのファミリー共有で写真が家族に見られたくない」という相談は多いのですが、実はこの3つはまったく別の機能です。

| | iCloud共有写真ライブラリ | 共有アルバム | ファミリー共有 |
| --- | --- | --- | --- |
| どんな機能か | 最大6人で使う、もう1つの完全なライブラリ | 選んだ相手と共有する個別のアルバム | 購入した項目、サブスクリプション、iCloud+ストレージを分け合うグループ |
| 写真を自動で共有するか | カメラや在宅時に自動で共有することがある | しない（自分で追加する） | しない |
| 編集・削除できる人 | 参加者全員 | 所有者（許可すれば参加者も追加可能） | 該当なし |
| 「高度なデータ保護」でのエンドツーエンド暗号化 | 参加者全員がオンなら対象 | 対象外 | 各自の個人用ライブラリは本人の設定に従う |

ファミリー共有をオンにしただけで、写真が家族に見られることはありません。見られているなら、共有ライブラリか共有アルバムに入っているか、家族があなたのApple Accountを使っているかのどちらかです。

## 暗号化はどうなっている？

iCloud写真は暗号化されていますが、初期設定の標準のデータ保護では鍵をAppleが保持しています。「高度なデータ保護」では、Appleの説明によると、共有コンテンツがエンドツーエンドで暗号化されるのは**参加者全員が**オンにしている間だけです。オンにしていない家族が1人でもいれば、共有ライブラリはその保護を失います。共有アルバムはそもそも対象外です。オンにする方法と注意点は、[iCloudの「高度なデータ保護」とは](id:icloud-advanced-data-protection-explained)で解説しています。

「家族写真を暗号化したい」と考えている人への正直な答えはこうです。Appleの仕組みで最も近いのは、参加者全員が「高度なデータ保護」をオンにした共有ライブラリです。暗号化が守るのはAppleのサーバー上の写真であって、写真を見るために参加しているほかの5人から守るものではありません。

## 別の暗号化保管庫が役立つ場面

共有ライブラリは共有するための機能です。絶対に共有したくない写真は、「写真」のライブラリから完全に外しておくほうが確実です。

Velcryptは、まさにそのためのiPhone用保管庫アプリです。読み込んだ写真、ビデオ、書類はiPhone上でAES-256-GCMにより暗号化され、デバイスのパスコードやFace IDではなく、5×5のグリッドに描くパターンで開きます。[アカウントもサーバーも同期もなく](id:offline-no-account)、保管庫のデータはiCloudやコンピュータのバックアップから除外されるため、保管庫の中身が共有ライブラリや共有アルバム、家族のiPadに表示されることはありません。パターンごとに別の保管庫が開くので、見られても困らないダミー保管庫を用意しておくこともできます。

読み込むと暗号化されたコピーが作られますが、元の写真は残ります。読み込んだあと「写真」で元の写真を削除し、「最近削除した項目」も空にしてください。写真が共有ライブラリにあった場合は、先に個人用ライブラリへ移動するか共有ライブラリで削除します。「最近削除した項目」から完全に削除できるのは、追加した本人だけである点も覚えておきましょう。

正直なトレードオフもあります。保管庫は共有には使えず、あなたのiPhoneの中にしか存在しません。パターンを忘れると復元できません。iPhoneの紛失に備えて、「設定」→「バックアップ」で暗号化バックアップファイルを作り、安全な場所に保管してください。保管庫から写真を書き出すと、暗号化されていない通常のコピーになります。
