App Storeでは、驚くほど多くの「電卓」が実は電卓ではありません。仮装した写真保管庫です。発想は巧みで、電卓をじっくり見る人はいません。しかし見られたくないものを任せる前に、その仮装が何をして、何をしないのかを正確に理解しておく価値があります。

## 電卓の偽装の仕組み

電卓型の保管庫とは、一般的な電卓のように見えて、そのように動作するよう作られた写真保管庫アプリです。アイコンは電卓に似ていて、ホーム画面の名前もたいてい「電卓」のようなもので、開くと実際に計算ができます。保管庫が現れるのは、秘密のコードを入力したときだけです。多くの場合、数字のあとに**=**や**%**などの特定のキーを押します。

さらに凝ったものもあります。偽の「最近の計算」履歴、無害なギャラリーを開くおとりのコード、間違ったコードが入力されるとアプリがクラッシュしたり閉じたりするオプションなどです。機能は開発者によって大きく異なります。

## 偽装は暗号化ではない

ここでは、2つの異なる問いに答えています。

- **偽装**が答えるのは「このiPhoneに保管庫があると気づかれるか」。
- **暗号化**が答えるのは「誰かがファイルにたどり着いたとき、読めるか」。

暗号化とは、正しい鍵がなければ読めないようにデータを変換する処理のことです。電卓の偽装は、この問いには何の役にも立ちません。ファイルはきちんと暗号化されているかもしれないし、コード画面の奥のアプリの保存領域にある普通の画像ファイルかもしれません。電卓を見ても分かりません。ファイルの保存方法と、鍵とコードの関係を明確に説明しているかを確認しましょう。何を確認すべきかは[保管庫の安全性チェックリスト](id:are-photo-vault-apps-safe)で説明しています。

逆もまた然りで、偽装がまったくなくても強力な暗号化を備えた保管庫はあります。

## iOSが本当のアプリを明かす場所

iOSはアプリの正体を秘密にするようには作られていないため、偽装したアプリはいくつもの場所に痕跡を残します。どこを見ればよいか知っている人なら、見つけられます。

| 場所 | 明かされうること |
| --- | --- |
| **SpotlightとAppライブラリの検索** | アプリの本当の名前で検索したり、Appライブラリのカテゴリーを見たりすると表示されることがある |
| **「設定」›「一般」›「iPhoneストレージ」** | 数GBの容量を使っている「電卓」 |
| **スクリーンタイム** | 「電卓」を使っている時間 |
| **App Storeの購入履歴** | App Storeでのアプリの本当の名前とページ |
| **アイコンの長押し** | アプリの共有などのオプション。App Storeのページにたどり着ける |
| **電卓が2つある** | 削除していない限り、Apple純正の「計算機」もiPhoneに残っている |

容量の手がかりは特に避けにくいものです。写真や動画は容量を使い、iOSは各アプリのサイズを正直に表示します。相手が積極的に疑っている場合、偽装は思ったほど役に立たないことが多いです。

## それでも偽装が役立つ場面

だからといって、電卓型の保管庫が無意味なわけではありません。いくつかの状況では、偽装にも本当の価値があります。

- **何気なく見られる場面。**ホーム画面をちらっと見た子ども、友人、同僚が、電卓を調べることはまずありません。
- **質問を避けたい場合。**なぜ「保管庫」アプリを持っているのか、説明したくない人もいます。
- **誰も何も探していない共有デバイス。**

相手が特定のものを探していたり、アプリを開くよう迫ってきたりする可能性があるなら、偽装は薄い層にすぎません。そうした状況では、ほかの2つの考え方のほうが持ちこたえる傾向があります。

### iOS自体の機能でアプリを隠す

iOS 18以降では、ほとんどのアプリを長押しして、Face IDを必須にするか、アプリを非表示にするかを選べます。非表示にしたアプリはAppライブラリの一番下にある**非表示**フォルダに移り、Face ID、Touch ID、またはパスコードでロックされ、Spotlightにも表示されなくなります。保管庫に限らず、どのアプリにも使えるシステム機能です。「非表示」アルバムと同じ注意点があり、パスコードを知っている人ならこのフォルダを開けます。

### 偽装の代わりにもっともらしい否認を

もっともらしい否認とは、誰かがアプリを見たり、あなたに開かせたりしても、ほかに何かがあると証明するものが何もない、という考え方です。おとり保管庫はその一形態で、2つ目のコードで無害な領域が開きます。より強力なのは、どんなコードでも何かが開き、アプリが領域の数を一切認めない設計です。どちらも[おとり保管庫とは](id:what-is-a-decoy-vault)と[もっともらしい否認とは](id:plausible-deniability-explained)で説明しています。

## 電卓型の保管庫を選ぶ前に確認したいこと

1. 開発者は、ファイルを隠すだけでなく、どう暗号化しているかを説明しているか。
2. App Storeのプライバシーラベルには何が記載されているか。電卓型の保管庫の多くは広告で収益を得ており、たいていトラッキング用のSDKが含まれます。
3. アカウントやクラウドへのアップロードがあるか。それは任意か。
4. コードを忘れたとき、どうやってアクセスを取り戻すか。
5. 読み込みは写真のコピーで、元の写真がライブラリに残るか。

## Velcryptのアプローチ

Velcryptは、動く電卓のふりはしません。Premiumではホーム画面用に電卓、タイマー、定規などの別のAppアイコンを選べますが、開くとパターンのグリッドが表示されます。代わりに、アプリを開いたあとに何が起きるかに焦点を当てています。各保管庫は5×5のグリッドに描く独自のパターンで開き、アプリが見たことのないパターンでは、エラーも、ほかの保管庫の存在を証明するものもなく、空の保管庫が開くだけです（[隠し保管庫](id:hidden-vaults)）。ファイルはパターンから導出された鍵でAES-256-GCMにより暗号化され（[暗号化](id:encryption)）、すべてがデバイス上にとどまります。

トレードオフとして、iOS自体のアプリ非表示機能を使わない限り、アプリはホーム画面に表示されます。また保管庫の中身は自動ではバックアップされないため、暗号化バックアップを自分で作成していなければ、iPhoneの紛失やパターンを忘れることは、中身を失うことを意味します。直接の比較は[Velcryptと電卓型保管庫アプリの比較](id:velcrypt-vs-calculator-vault-apps)をご覧ください。
