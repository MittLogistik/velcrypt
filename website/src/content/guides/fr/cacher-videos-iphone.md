Cacher une vidéo fonctionne exactement comme cacher une photo : le bouton est donc simple. Les vraies difficultés sont propres à la vidéo : les clips arrivent de sources que vous n’avez pas choisies, ils sont lourds et existent souvent en plusieurs exemplaires. Ce guide couvre le masquage lui-même, puis ces détails spécifiques.

## Cacher une vidéo dans l’app Photos

1. Ouvrez **Photos** et touchez la vidéo.
2. Touchez **Plus (•••)**.
3. Choisissez **Masquer** et confirmez.

Pour cacher plusieurs vidéos, il est utile de filtrer d’abord. L’app Photos permet de parcourir les types de médias, dont une collection **Vidéos** (sous iOS 18, faites défiler jusqu’à la section des types de médias). De là, touchez **Sélectionner**, choisissez les clips, puis Plus › Masquer.

Les vidéos masquées rejoignent l’album Masqués, situé sous **Utilitaires** dans iOS 18 et versions ultérieures. Il est verrouillé par Face ID, Touch ID ou votre code tant que **Utiliser Face ID** est activé dans **Réglages › Apps › Photos** (Réglages › Photos sur les versions plus anciennes). Pour masquer l’album lui-même, voir [comment cacher des photos sur iPhone](id:hide-photos-iphone).

## Ce qui compte comme une vidéo

Une Live Photo est une image fixe accompagnée d’environ trois secondes de mouvement et de son. L’app Photos la traite comme une photo, pas comme une vidéo. Masquer une Live Photo masque les deux parties ensemble. Si vous avez transformé une Live Photo en vidéo, par exemple en l’enregistrant comme vidéo ou en créant une boucle exportée, ce nouveau fichier est un élément distinct qu’il faut masquer aussi.

Autres sources courantes de vidéos dans votre photothèque :

- **Enregistrements d’écran.** Tout ce qui est enregistré avec le bouton d’enregistrement d’écran du Centre de contrôle est sauvegardé dans Photos comme une vidéo normale, et iOS les regroupe aussi dans un type de média Enregistrements d’écran. L’enregistrement d’une conversation privée en dit autant qu’une capture d’écran.
- **Vidéos au ralenti et en mode Cinématique.** Elles apparaissent dans leurs propres types de médias, mais se masquent de la même façon.
- **Clips modifiés et doublons.** Enregistrer une version modifiée ou découper une vidéo en nouveau clip crée un second élément. Vérifiez l’original.

## Empêcher les messageries d’enregistrer des vidéos dans Photos

Beaucoup de vidéos privées ne passent jamais par l’app Appareil photo. Elles arrivent dans des messageries et sont enregistrées automatiquement : les masquer une fois ne suffit donc pas, la suivante atterrira aussi dans votre pellicule.

**WhatsApp.** Dans les réglages de WhatsApp, cherchez dans la section Discussions l’option **Enregistrer dans Photos** et désactivez-la. Chaque discussion peut passer outre ce réglage : ouvrez les discussions sensibles, touchez le nom du contact ou du groupe et vérifiez l’option de visibilité ou d’enregistrement des médias.

<!-- TODO verify iOS label -->

**Telegram.** Les réglages de données et de stockage de Telegram comportent des options pour enregistrer automatiquement les photos et vidéos reçues dans la galerie. Désactivez-les pour les discussions privées, les groupes et les canaux selon vos besoins.

**Autres apps.** Signal, Messenger et les apps similaires ont leurs propres réglages d’enregistrement des médias. Les noms de menus changent d’une version à l’autre : cherchez « enregistrer » ou « médias » dans les réglages de chaque app.

Désactiver ces options ne supprime pas les vidéos déjà enregistrées. Celles-ci doivent être masquées ou supprimées comme n’importe quel autre élément de Photos.

## Stockage : pourquoi les vidéos demandent plus d’anticipation

La taille d’une vidéo dépend surtout de la résolution et de la fréquence d’images. Une minute de vidéo 4K à 60 images par seconde peut peser plusieurs centaines de mégaoctets ; en 1080p à 30 i/s, c’est bien moins. Vous pouvez voir et modifier le format d’enregistrement dans **Réglages › Apps › Appareil photo** sous iOS 18 et versions ultérieures (Réglages › Appareil photo sur les versions plus anciennes).

Cela compte de trois façons :

| Situation | Effet sur le stockage |
| --- | --- |
| Masquer une vidéo | Aucun changement. Elle occupe le même espace dans l’album Masqués. |
| Photos iCloud avec Optimiser le stockage de l’iPhone | La vidéo en pleine taille peut n’exister que dans iCloud, avec une version allégée sur le téléphone. L’ouvrir ou l’exporter télécharge l’original. |
| Copier une vidéo dans une app de coffre-fort | La vidéo existe désormais en double tant que vous n’avez pas supprimé l’original de Photos et vidé Suppressions récentes. |
| Supprimer une vidéo | L’espace n’est libéré qu’une fois Suppressions récentes vidé, ou au bout d’environ 30 jours. |

Si vous comptez déplacer un gros lot de vidéos dans un coffre-fort, vérifiez d’abord l’espace libre dans **Réglages › Général › Stockage iPhone**. Importer quelques gigaoctets dans un coffre alors que les originaux sont encore dans Photos peut vite remplir un téléphone presque plein. Procéder par petits lots, et supprimer les originaux de chaque lot avant le suivant, garde les choses gérables. Le guide pour [supprimer les originaux après l’import](id:delete-original-photos-after-import) explique le nettoyage, iCloud compris.

## Les limites du masquage d’une vidéo

Les vidéos masquées se comportent comme les photos masquées. Elles s’ouvrent avec votre code, se synchronisent via Photos iCloud sur vos autres appareils (voir [les photos masquées sont-elles enregistrées dans iCloud ?](id:are-hidden-photos-saved-to-icloud)), et les apps disposant d’un accès complet à la photothèque peuvent, en principe, demander les éléments masqués. Une vidéo envoyée dans une conversation existe aussi toujours dans cette conversation et sur le téléphone du destinataire.

Pour une discrétion de courte durée face à des amis ou à la famille, l’album Masqués suffit généralement. Pour des vidéos qui vous nuiraient vraiment si elles étaient vues, une copie entièrement sortie de la photothèque est plus sûre.

## La place de Velcrypt

Velcrypt stocke les vidéos dans un coffre-fort chiffré sur l’appareil, avec la même protection que pour les photos : chiffrement AES-256-GCM, verrouillage par schéma indépendant du code de votre iPhone, ni envoi en ligne ni compte. Dans le coffre, vous pouvez classer les clips dans des [albums](id:albums) et les lire dans la visionneuse intégrée. La page [cacher des vidéos avec Velcrypt](id:hide-videos) donne les détails.

Deux précisions honnêtes, propres à la vidéo. L’import copie le fichier : l’espace utilisé double tant que vous n’avez pas retiré l’original de Photos et de Suppressions récentes. Et les données du coffre ne sont pas incluses dans les sauvegardes iCloud ou sur ordinateur : si vous perdez le téléphone ou oubliez le schéma, les vidéos du coffre sont perdues. Gardez-le en tête avant de supprimer la seule autre copie de quelque chose que vous tenez à conserver.
