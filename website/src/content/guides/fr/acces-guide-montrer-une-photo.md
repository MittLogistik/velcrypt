Vous voulez montrer une photo, et la personne tend la main vers l’écran et balaie. Cela arrive à tout le monde et, sur un téléphone rempli d’images privées, c’est parfois plus que gênant. iOS dispose d’un outil pour cela que la plupart des gens ne trouvent jamais, parce qu’il se cache dans les réglages d’accessibilité : l’Accès guidé.

## Qu’est-ce que l’Accès guidé

L’Accès guidé est une fonction d’accessibilité d’iOS qui bloque l’iPhone sur une seule app et permet de désactiver certaines zones de l’écran, ou tout le toucher, jusqu’à la saisie d’un code. Il a été conçu pour les enseignants, les parents et les personnes ayant des besoins d’attention ou de motricité, mais c’est aussi le moyen le plus fiable de confier un téléphone qui affiche une chose et rien d’autre.

## Le configurer une fois

Cette étape n’est nécessaire que la première fois.

1. Ouvrez **Réglages › Accessibilité › Accès guidé**.
2. Activez **Accès guidé**.
3. Touchez **Réglages des codes** › **Définir le code d’Accès guidé** et choisissez un code. Il peut différer du code de l’appareil ; choisissez quelque chose que l’autre personne ne devinera pas.
4. Activez éventuellement **Face ID** (ou Touch ID) sur le même écran pour terminer les sessions plus vite.

## Montrer une seule photo

1. Ouvrez **Photos** et affichez la photo à montrer. Zoomez ou recadrez la vue maintenant si besoin : vous ne pourrez plus la modifier une fois le toucher désactivé.
2. **Appuyez trois fois sur le bouton latéral.** Sur un iPhone doté d’un bouton principal, appuyez trois fois sur celui-ci.
3. L’écran d’Accès guidé apparaît. Touchez **Options** en bas à gauche.
4. Désactivez **Toucher**. Laissez aussi **Bouton latéral** désactivé (c’est le réglage par défaut), pour qu’on ne puisse pas verrouiller puis déverrouiller l’écran pour s’échapper.
5. Touchez **OK**, puis **Démarrer** en haut à droite.

La photo est maintenant figée à l’écran. Balayages, touchers et pincements n’ont aucun effet, et la personne ne peut ni revenir à la photothèque ni changer d’app.

### Terminer la session

Appuyez de nouveau trois fois sur le bouton latéral, saisissez votre code d’Accès guidé et touchez **Fin**. Si vous avez activé Face ID pour l’Accès guidé, deux appuis sur le bouton latéral en regardant le téléphone fonctionnent aussi.

## Affiner au lieu de désactiver tout le toucher

Désactiver Toucher est le réglage le plus infaillible. Sur l’écran de démarrage de l’Accès guidé, vous pouvez à la place entourer des zones de l’écran pour les désactiver, ce qui laisse le reste de l’écran interactif. C’est pratique pour des apps dont vous voulez bloquer certains boutons, mais pas pour les photos : le geste de balayage fonctionne sur toute l’image, si bien qu’une zone bloquée empêche rarement de passer à l’image suivante. Pour les photos, désactivez complètement le toucher.

## Les accrocs fréquents

**Le triple appui fait autre chose.** Le triple appui est le raccourci d’accessibilité. Si plusieurs fonctions y sont associées (comme Loupe ou VoiceOver), un menu s’affiche ; choisissez Accès guidé. Vous pouvez modifier les fonctions associées dans **Réglages › Accessibilité › Raccourci accessibilité**.

**L’écran s’éteint.** Si le verrouillage automatique est court, l’écran peut s’assombrir pendant un long visionnage. Vous pouvez définir un verrouillage automatique distinct pour l’Accès guidé dans ses réglages.

**Vous avez oublié le code d’Accès guidé.** Si Face ID est activé pour l’Accès guidé, utilisez-le. Sinon, un redémarrage forcé met fin à la session ; la procédure varie selon le modèle et figure sur [l’assistance Apple](https://support.apple.com/).

## Ce que l’Accès guidé ne fait pas

L’Accès guidé sert à contrôler l’écran, pas à protéger votre vie privée en général. Quelques points à garder en tête :

- **Il montre exactement ce qui est à l’écran.** Tout ce qui est visible sur la photo, y compris les détails à l’arrière-plan, est visible pour la personne qui tient le téléphone. Si la photo montre un lieu ou un visage que vous préférez ne pas partager, recadrez d’abord une copie.
- **Il n’empêche pas un appareil photo.** Quelqu’un peut photographier votre écran avec son propre téléphone, et l’Accès guidé n’y peut rien.
- **Il repose sur son propre code.** Si le code d’Accès guidé est court ou identique à celui de l’appareil, et que l’autre personne le connaît, elle peut terminer la session et naviguer librement.
- **Il s’arrête si le téléphone redémarre.** Un redémarrage forcé fait sortir de l’Accès guidé, même si la personne se retrouve ensuite face à votre écran verrouillé.

## Des alternatives qui évitent de confier votre téléphone

L’Accès guidé est astucieux, mais le téléphone le plus sûr est celui qui ne quitte jamais votre main. Selon la situation, l’une de ces options peut être plus simple :

| Approche | Comment | Contrepartie |
| --- | --- | --- |
| Tenir le téléphone vous-même | Montrer la photo sans lâcher le téléphone | Le plus simple, mais peu pratique pour regarder de près |
| Envoyer une photo par AirDrop | Partager › AirDrop vers son appareil | La personne garde une copie |
| L’envoyer dans Messages | Partager › Messages | La personne garde une copie, qui reste dans la conversation |
| Masquer le reste d’abord | Masquer les photos sensibles voisines avant de montrer | Prend du temps ; laisse parcourir ce qui n’est pas masqué |
| Accès guidé | Comme ci-dessus | Une minute de configuration la première fois |

Envoyer une copie est la bonne réponse quand la personne doit garder la photo. C’est la mauvaise quand elle ne devrait pas la garder, car une copie sur l’appareil de quelqu’un d’autre échappe à votre contrôle. Si la situation concerne des enfants qui empruntent votre téléphone, voir [prêter son téléphone aux enfants](id:sharing-phone-with-kids). S’il s’agit d’un partenaire qui fait défiler votre pellicule, voir [quand votre partenaire fait défiler vos photos](id:partner-scrolling-camera-roll).

Pour les photos que vous ne voulez jamais voir surgir au détour d’un balayage, les masquer est une solution plus durable. [Comment cacher des photos sur iPhone](id:hide-photos-iphone) et [comment verrouiller ses photos sur iPhone](id:lock-photos-iphone) présentent les options.

## La place de Velcrypt

L’Accès guidé fonctionne dans presque toutes les apps, y compris les apps de coffre-fort. Soyons clairs sur ce que cela signifie pour Velcrypt : si vous ouvrez un coffre et tendez le téléphone, la personne voit ce qui est à l’écran et, sans Accès guidé, elle pourrait faire défiler l’album. Un coffre protège le contenu tant qu’il est verrouillé ; il ne peut pas protéger un contenu que vous avez ouvert et confié à quelqu’un.

Les bonnes habitudes sont donc les mêmes qu’avec Photos. Ne montrez une photo d’un coffre que si vous tenez vous-même le téléphone, ou utilisez l’Accès guidé avec le toucher désactivé. Quand vous quittez l’app, Velcrypt [se verrouille automatiquement](id:auto-lock) après le délai choisi et masque son contenu dans le sélecteur d’apps : un prêt rapide après l’avoir fermé ne révèle rien.
