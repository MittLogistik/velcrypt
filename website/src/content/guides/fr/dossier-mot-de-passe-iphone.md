L’app Fichiers ressemble beaucoup à un explorateur de fichiers d’ordinateur : on s’attend donc aux mêmes options, un clic droit sur un dossier, un mot de passe, et c’est réglé. iOS ne fonctionne pas ainsi. Fichiers n’a pas de verrou par dossier, ni de réglage caché qui en ajouterait un. Vous pouvez en revanche verrouiller l’app, verrouiller le contenu dans une autre app, ou déplacer les documents vers un endroit doté de son propre verrou.

## Pourquoi Fichiers n’a pas de mot de passe par dossier

L’app Fichiers est un navigateur d’emplacements de stockage : **Sur mon iPhone**, **iCloud Drive** et les services tiers que vous avez connectés. Elle montre leur contenu mais laisse le contrôle d’accès à iOS. La sécurité de l’iPhone repose sur un code unique pour l’appareil. Tant que le téléphone est verrouillé, les fichiers sont chiffrés par la Protection des données d’iOS ; une fois déverrouillé, Fichiers peut les montrer à quiconque tient le téléphone.

La vraie question n’est donc pas « comment protéger ce dossier par mot de passe », mais « comment empêcher quelqu’un qui utilise mon téléphone déverrouillé d’ouvrir ces documents ».

## Option 1 : verrouiller l’app Fichiers (iOS 18 et versions ultérieures)

iOS 18 a introduit le verrouillage d’apps, qui place une demande d’authentification devant une app à chaque ouverture.

1. Trouvez **Fichiers** sur l’écran d’accueil ou dans la bibliothèque d’apps.
2. Maintenez le doigt sur l’icône.
3. Choisissez **Exiger Face ID** (le libellé suit votre appareil : Touch ID ou code).
4. Confirmez.

Fichiers demande désormais Face ID avant d’afficher quoi que ce soit. Cela protège tous les dossiers de Fichiers, pas un seul, ce qui est un avantage ou une gêne selon la fréquence à laquelle vous l’utilisez.

Les limites sont celles de tout verrou intégré. Le recours est le code de l’appareil : quiconque le connaît peut ouvrir Fichiers. Le verrou ne s’applique qu’à l’app Fichiers ; les autres apps qui accèdent au même stockage, comme les apps de stockage en ligne ou celles qui ont leurs propres dossiers de documents, ne sont pas concernées. Les apps d’Apple ne peuvent généralement pas être placées dans le dossier des apps masquées, si bien que Fichiers reste visible sur l’appareil.

## Option 2 : une note verrouillée

Apple Notes peut verrouiller des notes une par une, les chiffrer et les protéger avec un mot de passe distinct du code de l’iPhone. Une note peut contenir des documents scannés, des photos et des pièces jointes : une note verrouillée peut donc servir de petit dossier protégé.

1. Définissez un mot de passe personnalisé dans **Réglages › Apps › Notes › Mot de passe** (Réglages › Notes › Mot de passe avant iOS 18), ou choisissez d’utiliser le code de l’appareil.
2. Créez une note et ajoutez votre contenu. Le bouton appareil photo permet de scanner des documents directement dans la note, si bien qu’un document papier ne passe jamais par votre photothèque.
3. Touchez **Plus (•••)** › **Verrouiller**.

Vous pouvez regrouper plusieurs notes verrouillées dans un dossier de Notes, mais ce sont les notes qui sont verrouillées, pas le dossier. ## Option 3 : protéger des fichiers un par un

Certains types de fichiers peuvent avoir leur propre mot de passe :

- **PDF.** Plusieurs éditeurs de PDF et suites bureautiques savent enregistrer un PDF avec mot de passe. iOS lui-même n’a pas d’outil général pour cela.
- **Documents bureautiques.** Certaines apps de productivité gèrent les mots de passe de document ; la possibilité d’en définir un sur iPhone dépend de l’app.
- **Archives chiffrées.** Quelques gestionnaires de fichiers savent créer des archives protégées par mot de passe.

Ces solutions protègent un fichier à la fois, et les ouvrir puis les refermer peut laisser des copies déchiffrées dans des dossiers temporaires selon l’app. Elles sont utiles pour envoyer un fichier protégé à quelqu’un ; elles sont malcommodes comme rangement au quotidien.

## Option 4 : un coffre-fort chiffré

Une app de coffre-fort importe des documents dans son propre espace et les chiffre sous un secret que vous êtes seul à connaître. C’est, en pratique, le dossier protégé par mot de passe que Fichiers ne propose pas, avec l’avantage supplémentaire que le verrou n’est pas le code de l’appareil.

Pour en choisir une, vérifiez qu’elle chiffre réellement les fichiers (et ne se contente pas de les cacher), si elle envoie quoi que ce soit en ligne, et si elle peut importer depuis l’app Fichiers, puisque c’est là que vivent la plupart des documents. Pensez à supprimer ensuite l’original dans Fichiers : une copie importée ne supprime pas la source. S’il était dans iCloud Drive, vérifiez aussi **Suppressions récentes** parmi les emplacements de l’onglet Parcourir de Fichiers.

## Là où les documents s’accumulent sans que vous le remarquiez

Verrouiller un dossier n’a d’intérêt que si les fichiers sensibles s’y trouvent vraiment. Sur un iPhone, les documents s’entassent souvent dans quelques endroits prévisibles :

- **Téléchargements.** Safari et Mail enregistrent les fichiers dans un dossier Téléchargements de Fichiers, dans iCloud Drive ou Sur mon iPhone selon vos réglages Safari.
- **Pièces jointes de Mail.** Ouvrir une pièce jointe ne la supprime pas de l’e-mail. Le message reste dans votre boîte, sur chaque appareil qui la synchronise.
- **Messages et messageries.** Les PDF et scans envoyés ou reçus restent dans la conversation tant que vous ne les y supprimez pas.
- **Suppressions récentes dans Fichiers.** Les fichiers supprimés d’iCloud Drive ou de Sur mon iPhone vont dans un emplacement Suppressions récentes de l’onglet Parcourir, où ils patientent avant d’être effacés définitivement.

Avant de décider où placer votre dossier privé, mieux vaut passer ces emplacements en revue une fois.

## Quelle option choisir

| Besoin | Solution la plus adaptée |
| --- | --- |
| Empêcher l’accès occasionnel à tous mes fichiers | Verrouiller l’app Fichiers |
| Protéger quelques notes ou scans avec un mot de passe distinct | Notes verrouillées |
| Envoyer un fichier protégé à quelqu’un | PDF ou archive protégés par mot de passe |
| Garder pièces d’identité, dossiers médicaux ou contrats à l’abri de ceux qui connaissent mon code | Coffre-fort chiffré |

Pour les pièces d’identité et les documents de santé en particulier, le cas d’usage [documents médicaux et d’identité](id:medical-and-id-documents) apporte plus de contexte.

## La place de Velcrypt

Velcrypt range les [documents privés](id:private-documents) dans les mêmes coffres chiffrés que les photos et les vidéos. Vous les importez depuis l’app Fichiers, et ils sont chiffrés sur l’appareil en AES-256-GCM avec des clés dérivées de votre schéma de déverrouillage. Pas de compte, rien n’est envoyé sur un serveur ; la page sur le [stockage hors ligne et sans compte](id:offline-no-account) explique ce que cela signifie concrètement.

Comme les données du coffre sont exclues des sauvegardes iCloud et sur ordinateur, créez une sauvegarde chiffrée (Réglages → Sauvegarde) de tout document que vous ne pouvez pas vous permettre de perdre, et conservez-la dans un endroit de confiance. Si le schéma est oublié, personne ne peut ouvrir le coffre, pas même Velcrypt.
