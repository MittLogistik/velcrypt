Verrouiller va plus loin que masquer : au lieu de sortir les photos du champ de vision, vous placez une demande d’authentification devant elles. iOS propose plusieurs façons de le faire, chacune avec une portée différente, d’un seul album à l’app entière. Le bon choix dépend surtout d’une question : qui connaît déjà le code de votre iPhone ?

## Méthode 1 : l’album Masqués verrouillé

Le verrou le plus simple est celui qu’iOS applique déjà. Depuis iOS 16, les albums Masqués et Suppressions récentes exigent Face ID, Touch ID ou votre code pour s’ouvrir.

1. Ouvrez une photo, touchez **Plus (•••)** et choisissez **Masquer**.
2. Allez dans **Réglages › Apps › Photos** sous iOS 18 et versions ultérieures (**Réglages › Photos** sous iOS 16 et 17).
3. Vérifiez que **Utiliser Face ID** (ou Utiliser Touch ID / Utiliser le code) est activé.

Cela ne verrouille que ce que vous avez masqué. Le reste de la photothèque reste ouvert à quiconque prend votre téléphone déverrouillé. La marche à suivre complète, y compris pour retirer l’album Masqués de l’affichage, se trouve dans [comment cacher des photos sur iPhone](id:hide-photos-iphone).

## Méthode 2 : verrouiller toute l’app Photos (iOS 18 et versions ultérieures)

iOS 18 a introduit le verrouillage d’apps, une fonction système qui place une demande Face ID, Touch ID ou code devant une app à chaque ouverture.

1. Sur l’écran d’accueil ou dans la bibliothèque d’apps, maintenez le doigt sur l’icône **Photos**.
2. Choisissez **Exiger Face ID** (le libellé correspond à la méthode d’authentification de votre appareil).
3. Confirmez avec Face ID ou votre code.

Une fois Photos verrouillée, son contenu est aussi tenu à l’écart d’endroits comme les résultats de recherche et les aperçus de notifications. Pour annuler, maintenez de nouveau le doigt sur l’icône et choisissez l’option qui désactive l’exigence de Face ID.

Deux réserves. Les apps d’Apple peuvent être verrouillées, mais en général pas placées dans le dossier des apps masquées : tout le monde peut donc voir que Photos est là. Et le verrou concerne l’ouverture de l’app Photos elle-même ; il ne change rien aux autres apps qui ont accès à votre photothèque. Vérifiez cette liste dans **Réglages › Confidentialité et sécurité › Photos**, ou lisez [quelles apps peuvent voir vos photos](id:which-apps-can-see-your-photos-iphone).

Le verrouillage d’app convient bien si vous prêtez votre téléphone à des enfants ou à des collègues et voulez rendre toute la photothèque inaccessible, pas seulement quelques photos.

## Méthode 3 : placer les photos dans une note verrouillée

Une note verrouillée est une note de l’app Notes d’Apple, chiffrée, qui exige un mot de passe, Face ID ou votre code pour être consultée. Les notes peuvent contenir des photos et des vidéos, ce qui en fait un verrou photo improvisé.

1. Dans **Notes**, créez une note et ajoutez des photos avec le bouton appareil photo (nouvelle photo ou choix dans la photothèque).
2. Touchez **Plus (•••)** et choisissez **Verrouiller**.
3. La première fois, choisissez d’utiliser le code de l’iPhone ou un mot de passe Notes distinct. Ce choix se règle dans **Réglages › Apps › Notes › Mot de passe** sous iOS 18 et versions ultérieures.

<!-- TODO verify iOS label -->

Choisir un mot de passe Notes distinct est la seule option intégrée où le code de l’appareil, à lui seul, n’ouvre pas le contenu. Si vous oubliez ce mot de passe, Apple ne peut pas récupérer les notes.

Les inconvénients sont pratiques. Notes n’est pas une visionneuse photo : parcourir des dizaines d’images est pénible, et les vidéos sont malcommodes. Les photos ajoutées depuis la photothèque sont des copies, donc les originaux restent dans Photos tant que vous ne les supprimez pas. Les notes verrouillées se synchronisent aussi via iCloud si Notes utilise iCloud. La page [Velcrypt ou les notes verrouillées d’Apple Notes](id:velcrypt-vs-apple-notes-locked-notes) compare les deux plus en détail.

## Méthode 4 : une app de coffre-fort chiffré

Une app de coffre-fort stocke des copies de vos photos dans son propre espace chiffré et possède son propre verrou. La différence essentielle, c’est l’indépendance : le verrou n’est pas le code de votre appareil, donc les personnes qui connaissent ce code ne peuvent toujours pas ouvrir le coffre.

Les apps de coffre-fort sont très variées. Certaines utilisent un code PIN, d’autres un schéma, d’autres se déguisent en calculatrice ; certaines envoient les données vers leur propre cloud et exigent un compte, d’autres restent sur l’appareil. Avant de vous y fier, regardez comment elle chiffre, où vont les données et ce qui se passe si vous oubliez le code. [Les apps coffre-fort photo sont-elles fiables ?](id:are-photo-vault-apps-safe) propose une liste de vérification.

## Choisir son verrou

Si personne d’autre ne connaît votre code et que vous voulez surtout éviter qu’on fasse défiler vos photos par curiosité, l’album Masqués ou le verrouillage d’app suffisent ; les deux sont gratuits et intégrés.

Si un partenaire, un parent ou quelqu’un d’autre connaît votre code, il peut ouvrir toutes les méthodes intégrées, sauf une note protégée par un mot de passe distinct. C’est la situation où un verrou indépendant prend tout son sens.

Pensez aussi à la biométrie. Face ID est rapide, mais un visage peut être présenté sans réel consentement. [Schéma, code PIN ou Face ID](id:pattern-lock-vs-pin-vs-face-id) compare ces méthodes de déverrouillage entre elles.

## La place de Velcrypt

Velcrypt est un coffre-fort de la quatrième catégorie. Il n’utilise volontairement ni Face ID ni Touch ID : vous le déverrouillez en traçant un [schéma](id:pattern-lock) sur une grille de 5×5 points, d’au moins six points avec au moins un changement de direction, et les schémas plus longs sont préférables. Ce schéma n’existe que dans votre mémoire et n’a aucun lien avec le code de votre iPhone.

Le contenu est chiffré sur l’appareil en AES-256-GCM, le coffre [se verrouille automatiquement](id:auto-lock) quand vous quittez l’app, et rien n’est envoyé en ligne. Le prix de cette conception, c’est l’absence de récupération : si vous oubliez le schéma, ni vous ni Velcrypt ne pouvez ouvrir le coffre. Comme tout verrou, il ne peut rien non plus si quelqu’un vous regarde tracer le schéma ou si vous remettez le téléphone avec le coffre déjà ouvert.
