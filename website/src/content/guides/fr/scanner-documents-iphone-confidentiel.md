Votre iPhone est un scanner efficace, bien pratique pour une page de passeport, un bail ou un résultat d’analyse. Le problème, c’est que la méthode la plus évidente, prendre une photo, place une copie du document dans votre photothèque, dans iCloud, et peut-être dans les Souvenirs ou un album partagé. Quelques petits changements dans votre façon de scanner gardent les papiers sensibles là où vous le voulez.

## Pourquoi ne pas simplement prendre une photo ?

Une photo de document est traitée comme n’importe quelle autre photo. Elle apparaît dans votre pellicule, se synchronise via Photos iCloud, peut être trouvée par la recherche (iOS reconnaît le texte dans les photos), et toute app ayant un accès complet aux photos peut la lire. Même masquée, elle se synchronise toujours, comme l’explique [les photos masquées sont-elles enregistrées dans iCloud ?](id:are-hidden-photos-saved-to-icloud)

Un scanner de documents est un outil qui détecte les bords d’une page, redresse la perspective et enregistre le résultat comme document, généralement un PDF. iOS en intègre un à deux endroits qui ne touchent pas du tout à votre photothèque : l’app Fichiers et Notes.

## Option 1 : scanner avec l’app Fichiers

Fichiers est le meilleur choix quand vous voulez un PDF autonome à déplacer ailleurs.

1. Ouvrez **Fichiers** et allez dans l’onglet **Parcourir**.
2. Touchez le bouton **Plus** (trois points dans un cercle) en haut de l’écran.
3. Choisissez **Scanner des documents**.
4. Tenez l’iPhone au-dessus de la page. La capture se fait automatiquement quand la page est détectée, ou vous pouvez toucher le déclencheur. Ajustez les coins si besoin.
5. Scannez les pages suivantes si le document en compte plusieurs, puis touchez **Enregistrer**.
6. Choisissez l’emplacement. Prenez un dossier sous **Sur mon iPhone**, pas **iCloud Drive**.

### Où le scan est stocké

- **Sur mon iPhone** garde le fichier sur l’appareil. Il est protégé par la Protection des données d’iOS tant que le téléphone est verrouillé, et peut être inclus dans les sauvegardes de l’appareil.
- **iCloud Drive** envoie le fichier sur les serveurs d’Apple et le synchronise avec vos autres appareils. Il n’est chiffré de bout en bout que si la [Protection avancée des données](id:icloud-advanced-data-protection-explained) est activée.

Si l’écran d’enregistrement s’ouvre dans iCloud Drive, revenez en arrière jusqu’à la liste des emplacements, puis choisissez Sur mon iPhone. Vous pouvez y créer un dossier dédié aux scans.

## Option 2 : scanner dans Notes

Notes est pratique quand vous voulez un scan accompagné d’un peu de texte, par exemple un document et une courte note à son sujet.

1. Ouvrez **Notes** et créez une note.
2. Touchez le bouton des pièces jointes (une icône d’appareil photo sur les anciennes versions, un trombone sur les plus récentes) et choisissez **Scanner des documents**.
3. Scannez les pages et touchez **Enregistrer**. Le scan est intégré à la note.

### Où le scan est stocké

Le scan se trouve dans la note, pas dans Photos. L’endroit où vit la note dépend de son compte :

- Les notes **iCloud** se synchronisent sur tous vos appareils et sur les serveurs d’Apple.
- Les notes **Sur mon iPhone** restent sur l’appareil. Si vous ne voyez pas ce compte, cherchez une option pour activer un compte Sur mon iPhone dans les réglages de Notes (Réglages › Apps › Notes sous iOS 18 et versions ultérieures ; Réglages › Notes sur les versions plus anciennes).

### Verrouiller la note

Notes permet de verrouiller une note avec le code de l’appareil ou un mot de passe Notes distinct ; les notes verrouillées sont chiffrées. Ouvrez la note, touchez le bouton **Plus** et choisissez **Verrouiller**. Un mot de passe distinct ajoute une vraie couche supplémentaire, car le code de l’appareil seul ne l’ouvre pas. Notre comparaison [Velcrypt ou les notes verrouillées](id:velcrypt-vs-apple-notes-locked-notes) détaille les différences.

## Comparer les options

| | Appareil photo | Scanner de Fichiers | Scanner de Notes |
| --- | --- | --- | --- |
| Arrive dans la photothèque | Oui | Non | Non |
| Peut rester uniquement en local | Seulement si Photos iCloud est désactivé | Oui, avec Sur mon iPhone | Oui, avec un compte Sur mon iPhone |
| Verrou distinct | Album Masqués (code de l’appareil) | Non | Mot de passe Notes facultatif |
| Facile à déplacer vers une autre app | Oui | Oui (PDF) | Via le bouton de partage |

## Un mot sur les apps de scan tierces

Beaucoup d’apps de scan de l’App Store proposent la reconnaissance de texte, le stockage cloud ou la synchronisation automatique. Certaines de ces fonctions traitent vos pages sur des serveurs distants. Pour un ticket de caisse, cela importe peu ; pour un passeport ou un compte rendu médical, cela peut compter. Avant d’en utiliser une, vérifiez son étiquette de confidentialité sur l’App Store et si elle exige un compte, et essayez-la en mode Avion. Notre [guide des coffres sans compte](id:photo-vault-without-account) explique ces vérifications.

## Placer les scans dans un coffre-fort chiffré

Verrouiller une note ou garder un PDF dans Sur mon iPhone est un bon début, mais quiconque peut déverrouiller votre téléphone peut quand même ouvrir Fichiers. Pour les pièces d’identité, les dossiers médicaux et tout ce dont la fuite vous serait insupportable, placer le scan dans un coffre-fort chiffré ajoute un secret distinct.

Velcrypt peut importer des documents depuis l’app Fichiers dans un coffre chiffré ([documents privés](id:private-documents)). Les fichiers sont chiffrés sur l’appareil en AES-256-GCM avec des clés dérivées de votre schéma de déverrouillage, et rien n’est envoyé en ligne ([hors ligne, sans compte](id:offline-no-account)). Velcrypt n’a pas de scanner de documents : vous scannez d’abord avec Fichiers ou Notes, puis vous importez le PDF. Son appareil photo intégré au coffre peut aussi photographier une page directement dans le coffre, sans recadrage.

Gardez en tête que le contenu du coffre n’est pas inclus dans les sauvegardes iCloud ou sur ordinateur. Si un document original est irremplaçable, créez une sauvegarde chiffrée dans Réglages → Sauvegarde, ou conservez la version papier dans un endroit que vous contrôlez. Notre [cas d’usage sur les documents médicaux et d’identité](id:medical-and-id-documents) aborde cet équilibre.

## Nettoyer les restes

Importer un scan dans n’importe quel coffre le copie. L’original reste là où vous l’avez enregistré tant que vous ne le supprimez pas, et la suppression n’est pas la fin non plus.

1. **Fichiers :** supprimez le PDF, puis allez dans **Parcourir › Suppressions récentes** et supprimez-le là aussi.
2. **Notes :** supprimez la note, puis ouvrez le dossier **Suppressions récentes** de Notes et supprimez-la définitivement.
3. **Photos :** si vous avez un jour photographié le document, supprimez la photo et videz **Suppressions récentes** dans Utilitaires. Notre [guide pour supprimer les originaux](id:delete-original-photos-after-import) donne les détails.
4. **Copies partagées :** si vous avez envoyé le scan par e-mail ou dans une conversation, ces copies restent dans le dossier des envois et sur l’appareil du destinataire.

Les éléments de Suppressions récentes sont conservés jusqu’à 30 jours : cette étape compte.

## Précautions supplémentaires pour les documents sensibles

- **Recadrez ce qui est inutile.** Si un formulaire ne demande qu’une page, ne scannez pas tout le livret.
- **Surveillez l’arrière-plan.** Un scan peut inclure votre bureau, une lettre portant votre adresse ou des reflets.
- **Attention aux métadonnées des photos.** Les scans de Fichiers et de Notes sont des PDF, mais si vous utilisez une photo, elle peut contenir la position ; voir [supprimer les métadonnées d’une photo](id:remove-photo-metadata-iphone).
- **Partagez délibérément.** Quand un organisme demande une copie, n’envoyez que ce document, et pensez à ajouter avec l’outil Annotation un filigrane indiquant à qui il est destiné.
