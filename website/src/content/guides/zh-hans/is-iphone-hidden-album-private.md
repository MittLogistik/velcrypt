想把一张照片藏起来时，大多数 iPhone 用户首先会想到“已隐藏”相簿。它确实有用，但“隐藏”和“私密”不是一回事。这篇指南会具体讲清这个相簿做了什么、它的保护在哪里止步，以及谁仍然能进去。

## “已隐藏”相簿实际做了什么

“已隐藏”相簿是“照片”App 中的一个内置合集，存放你标记为隐藏的项目。当你隐藏一张照片或一段视频时，iOS 会把它从主“图库”网格、其他相簿、“照片”小组件，以及“回忆”和“精选照片”等功能中移除。文件本身并没有被移到什么特别的地方：它仍在同一个照片图库中，只是被标记为隐藏。

从 iOS 16 起，“已隐藏”和“最近删除”相簿默认锁定。打开其中任何一个都需要 Face ID、Touch ID 或设备密码。根据 iOS 版本不同，这个相簿的位置也不同：

| iOS 版本 | “已隐藏”相簿的位置 |
| --- | --- |
| iOS 18 及更高版本 | “照片”App，向下滚动到 **“实用工具”**，然后是 **“已隐藏”** |
| iOS 16 和 iOS 17 | “相簿”标签页，向下滚动到 **“实用工具”**，然后是 **“已隐藏”** |
| iOS 15 及更早版本 | “相簿”标签页，**“已隐藏”**（无锁） |

## 它的保护在哪里止步

“已隐藏”相簿擅长一件事：别人翻你的相册时，不让照片出现。如果你想要的不止这些，有几个局限很关键。

### 密码始终是备用方式

“已隐藏”相簿的锁就是你的设备锁。如果 Face ID 不认识拿着手机的人，iOS 会改为提供密码输入。所以能打开你“已隐藏”相簿的人，正是那些知道你 iPhone 密码的人：伴侣、家人，或者看过你输入密码的人。这个相簿没有单独的密码。

### 它不是一个独立的加密空间

锁定的 iPhone 上，每个文件都受 iOS 数据保护，隐藏的照片也不例外。但隐藏并不会再加一层使用独立密钥的加密。一旦手机解锁，并用设备凭证打开相簿，里面的一切都可以读取。对比一下使用独立密钥（从只有你知道的“秘密”派生）的保险箱，我们在 [AES-256 加密详解](id:aes-256-encryption-explained) 中有解释。

### 它的存在一目了然

任何人打开“照片”并滚动到“实用工具”，都能看到有一个“已隐藏”相簿。除非你把这个相簿关掉，否则它并不能掩盖“你在隐藏某些东西”这一事实，而这在某些情况下很重要（参见 [合理推诿详解](id:plausible-deniability-explained)）。

### 生物识别可以在你不配合的情况下被使用

Face ID 和 Touch ID 很方便，但在你睡着、被控制住或仅仅是受到压力时，你的脸或手指都可能被拿来解锁。对有些人来说，这是一个现实的考量，我们在 [图案锁、PIN 码与 Face ID 对比](id:pattern-lock-vs-pin-vs-face-id) 中有讨论。

## 在 iCloud 中会发生什么

如果开启了 iCloud 照片，隐藏的照片会像其他项目一样同步。它们会出现在你 iPad 和 Mac 的“已隐藏”相簿中，并存储在 Apple 的服务器上。Apple 在技术上能否读取它们，取决于你账户的安全设置：

- **标准数据保护**（默认）：照片在传输过程中和在 Apple 服务器上都是加密的，但 Apple 持有密钥。这意味着 Apple 可以解密它们，例如在法律要求时。
- **高级数据保护**：“照片”是端到端加密的，只有你的受信任设备持有密钥。

我们在 [隐藏的照片会存到 iCloud 吗？](id:are-hidden-photos-saved-to-icloud) 和 [iCloud 高级数据保护详解](id:icloud-advanced-data-protection-explained) 中有更详细的介绍。

另外请记住，iCloud 是一个账户，而不是一台设备。任何在另一台设备上登录你 Apple 账户的人，或者在允许网页访问时登录 iCloud.com 的人，都可能访问你的图库，包括“已隐藏”相簿，只不过同样受那台设备上锁定行为的约束。

## 到底谁能看到你隐藏的照片

下面简单总结一下谁能、谁不能进入“已隐藏”相簿：

| 人员或情况 | 能看到隐藏的照片吗？ |
| --- | --- |
| 随手翻看你已解锁相册的人 | 不能，隐藏的项目不会出现在“图库”中 |
| 知道你设备密码的人 | 能，密码就能打开相簿 |
| 能访问你 Apple 账户的人 | 可能，在登录该账户的设备或网页上 |
| 与你共享 iCloud 家庭方案的人 | 不能，“家人共享”不会共享你的个人图库 |
| iCloud 共享图库的参与者 | 只能看到你放进共享图库的项目；请把私密照片留在个人图库中 |
| Apple | 在标准数据保护下技术上可以；打开高级数据保护后不能 |

如果你使用 iCloud 共享图库，隐藏照片之前请先确认它属于哪个图库。我们关于 [家庭共享 iCloud 设置](id:family-shared-icloud) 的指南解释了两者的区别。

## 如何让“已隐藏”相簿尽可能私密

如果你认为“已隐藏”相簿足以应对你的情况，几个设置可以让它明显更可靠：

1. **保持锁定开启。** 在“设置”›“App”›“照片”（iOS 18+）或“设置”›“照片”中，确认“已隐藏”相簿的面容 ID / 触控 ID / 密码选项已启用。
2. **使用强设备密码。** 6 位数字是最低要求；更长的字母数字密码更好，并且绝不要告诉别人。
3. **打开高级数据保护**，前提是你可以使用这项功能，并且能管理好它的恢复要求。
4. **考虑把相簿本身也隐藏起来**，使用“显示‘已隐藏’相簿”开关。
5. **整理之后清理“最近删除”**，因为删除的项目会在那里保留大约 30 天。

## 什么时候独立的保险箱更合适

“已隐藏”相簿是为整理和轻度隐私设计的，并不适用于身边有人知道你的密码、或可能逼你解锁手机的情况。在这些情况下，你通常需要一个有自己“秘密”和自己加密的空间。

Velcrypt 采用的就是这种思路。每个保险箱都用在 5×5 点阵上画出的图案打开，而不是用 Face ID 或设备密码，其内容用从该图案派生出的密钥以 AES-256-GCM 加密（[加密如何运作](id:encryption)）。每个图案打开各自的保险箱，陌生的图案只会打开一个空保险箱，所以没有任何东西会透露存在多少个保险箱（[隐藏保险箱](id:hidden-vaults)）。所有内容都留在设备上，不需要账户，也没有云端副本。

这也带来了需要坦诚说明的取舍。保险箱内容不包含在 iCloud 或电脑备份中，所以如果你忘了图案，或丢了手机却没有创建过加密备份文件，内容就无法恢复。而且导入照片是复制，所以你仍需从“照片”和“最近删除”中移除原图。想看并排对比，请阅读 [Velcrypt 与 iPhone“已隐藏”相簿对比](id:velcrypt-vs-iphone-hidden-album)。
