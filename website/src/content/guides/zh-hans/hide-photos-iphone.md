搜索这个问题的人，想要的通常是同一件事：别人翻相册时，某张照片不要出现在里面。iOS 自带的功能就能做到，只需几秒钟。但它不会把照片变成只有你能打开的东西，所以最好先弄清楚它的边界在哪里。

## 用“照片”App 隐藏照片

“已隐藏”相簿是“照片”App 里的一个特殊相簿，用来存放你选择从主图库视图中移走的项目。被隐藏的照片会从图库网格、普通相簿和大多数推荐中消失，但并没有被删除。

1. 打开 **“照片”**，轻点那张照片或视频。
2. 轻点 **“更多”（•••）** 按钮。
3. 选择 **“隐藏”** 并确认。

要一次隐藏多个项目，在图库中轻点 **“选择”**，逐个轻点缩略图，然后使用屏幕底部的“更多”按钮并选择 **“隐藏”**。你也可以长按某个缩略图，不用打开就直接从菜单里选择 **“隐藏”**。

照片、视频、实况照片和截屏都可以隐藏。如果你只隐藏了连拍中的一张或重复照片中的一张，那么只有这一张会被隐藏，所以最好检查一下有没有几乎一样的副本。

## 找到“已隐藏”相簿

相簿的位置取决于你的 iOS 版本：

- **iOS 18：** 打开“照片”，向下滚动到 **“实用工具”**。“已隐藏”和“最近删除”等系统合集都在这里。
- **iOS 26：** “照片”App 分为图库和合集两个视图。请在合集视图中找“实用工具”部分。
- **iOS 16 和 17：** 打开 **“相簿”** 标签页，滚动到底部的“实用工具”下面。

## 锁定并隐藏“已隐藏”相簿

有两个设置决定这个相簿有多“显眼”。在 iOS 18 及更高版本中，它们都在 **“设置”›“App”›“照片”**；在更早的版本中，它们在 **“设置”›“照片”**。

**“使用面容 ID”**（没有 Face ID 的设备上为 **“使用触控 ID”** / **“使用密码”**）。从 iOS 16 起它默认开启，打开“已隐藏”和“最近删除”相簿之前需要验证身份。保持开启即可，几乎没有理由关闭它。

**“显示‘已隐藏’相簿”。** 关闭后，“已隐藏”相簿会从“照片”App 中彻底消失。别人翻你的手机时，根本看不到可以点的“已隐藏”入口。想再看隐藏的照片时，把这个设置重新打开就行。

## 隐藏保护不了什么

隐藏是一个“可见性”功能。它很实用，但在用它保护敏感内容之前，值得把它的局限说清楚。

| 情况 | “已隐藏”相簿有用吗？ |
| --- | --- |
| 有人翻你的相册 | 有用，隐藏的项目不在网格里 |
| 有人知道你的锁屏密码 | 没用，密码就能打开相簿 |
| 手机已解锁并交给别人 | 部分有用；Face ID 仍守着相簿，但任何知道密码的人都能用密码打开 |
| 开启了 iCloud 照片 | 隐藏的项目会同步到你的其他设备和 iCloud |
| 家人使用你的 Mac 或 iPad | 他们可能在那台设备上找到同一个“已隐藏”相簿 |
| 照片也在聊天中发送过 | 聊天里的副本不受影响 |

密码这一点最关键。Face ID 是第一道提示，但 iOS 始终提供设备密码作为备用方式。伴侣、家人，或者任何看过你解锁手机的人，通常都能打开“已隐藏”相簿。

第二点是 iCloud。开启 iCloud 照片后，隐藏的照片会像图库里的其他照片一样存储在 iCloud 中。只有打开了“高级数据保护”，它们才是端到端加密的；否则 Apple 持有你照片数据的密钥。关于 [隐藏的照片会不会存到 iCloud](id:are-hidden-photos-saved-to-icloud) 和 [iCloud 高级数据保护](id:icloud-advanced-data-protection-explained) 的指南有详细说明，[iPhone “已隐藏”相簿真的私密吗？](id:is-iphone-hidden-album-private) 则更全面地分析了这个相簿的隐私性。

最后，你授予了“完全访问”照片图库权限的 App，原则上可以通过 Apple 的照片框架请求隐藏的项目。养成定期检查这份列表的习惯：请看 [哪些 App 能看到你的照片](id:which-apps-can-see-your-photos-iphone)。

## 什么时候更适合用加密保险箱

加密保险箱是一种 App，它把照片的副本存放在自己的存储空间里，并用只有你的“秘密”才能解开的密钥加密。它和“已隐藏”相簿是不同的工具：它不是在照片图库里把项目藏起来，而是把它们从图库里拿出来。

在以下情况下，多这一步是值得的：

- 别人知道你的 iPhone 密码，或者可能逼你解锁；
- 你在用 iCloud 照片，不希望某些图片出现在云端图库里；
- 你和家人共用设备或 Apple 账户；
- 内容一旦被看到会造成真正的伤害（证件扫描件、医疗照片、私密照片）。

代价是责任。只把数据保存在你设备上的保险箱，如果你丢了手机或忘了怎么解锁，是无法帮你恢复的。

## Velcrypt 的定位

Velcrypt 就是第二种方式的一个例子。你在 5×5 的点阵上画出图案来解锁，而不是用 Face ID 或设备密码，所以知道你的 iPhone 密码也打不开它。文件在设备上用 AES-256-GCM 加密，不需要账户，保险箱数据也不会包含在 iCloud 备份中。每个图案都会打开各自独立的保险箱，没见过的图案只会打开一个空保险箱；[隐藏保险箱](id:hidden-vaults) 页面解释了这为什么重要。

把照片导入 Velcrypt 是复制而不是移动，所以原图会一直留在“照片”里，直到你自己删除它，包括从“最近删除”中删除。[导入后删除原图](id:delete-original-photos-after-import) 的指南会一步步带你完成。想了解这款 App 在照片方面的功能，请看 [用 Velcrypt 隐藏照片](id:hide-photos)；想看并排对比，请看 [Velcrypt 与 iPhone“已隐藏”相簿对比](id:velcrypt-vs-iphone-hidden-album)。
