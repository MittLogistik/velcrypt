大多数安全措施都是为了把陌生人挡在门外。胁迫密码针对的是另一种时刻：有人就站在你身边，逼你让他进去。本指南介绍胁迫密码是什么、这个概念从何而来、胁迫暗语如何运作、iPhone 和 Android 提供哪些功能、手机 App 如何使用它，以及 Velcrypt 的胁迫图案如何运作，包括它的局限。

## 胁迫密码是什么

**胁迫密码**是第二个秘密，只在你被胁迫时使用。在旁观者看来，输入它和正常解锁一模一样。但在后台，它会额外做一些事情来保护你或你的数据。

同一个概念有好几种叫法：

- **胁迫码**，报警系统和安保设施中的常用说法。
- **紧急密码**、**应急密码**或**紧急 PIN**，在 App 中很常见。
- **胁迫 PIN** 或**胁迫图案**，取决于设备的解锁方式。

它的决定性特征是反应**无声**。如果输入这个码会引发警报声、警告信息或明显的变化，反而会让你陷入更大的危险，因为逼你的人会知道你反抗了。

## 这个概念从何而来

### 报警系统

许多家用和商用报警面板都支持胁迫码。你在键盘上输入它，报警会像平常一样解除，所以逼你解除报警的入侵者看不到任何异常。与此同时，面板会悄悄通知监控中心你遇到了麻烦。

报警系统的胁迫码通常只有在开通专业监控服务时才有效，而且一旦输入，即使只是测试，也会请求真实的紧急出警。报警服务商和警方还提醒，与平时密码太相似的胁迫码容易造成误报，所以请选一个不会混淆的。

### 银行和安保设施

银行职员很早就有无声警报和胁迫信号：一个按钮、一个暗语或一个代码，可以通知安保人员而不惊动劫匪。目标和报警面板一样：表面上配合，暗地里求救。

你可能听说过在 ATM 上倒着输入 PIN 码就会报警。这是谣言。这个想法源于 20 世纪 90 年代一项“紧急 PIN”专利，但美国联邦贸易委员会（FTC）工作人员 2010 年的报告发现，这类系统从未在 ATM 上部署过，事实核查机构也多次辟谣。如果你在 ATM 遭遇抢劫，为了安全先满足对方的要求，之后再报警并联系银行。

### 加密软件

磁盘加密工具引入了一个相关的概念：第二个密码会打开一个看起来可信的外层卷，而隐藏卷始终不被看见。严格来说这不是胁迫码，因为它不会触发任何东西，但它们的目标相同：让“部分让步”成为安全的选项。[合理推诿详解](id:plausible-deniability-explained)介绍了这段历史。

## 胁迫暗语：说出口的胁迫密码

**胁迫暗语**（英文 *duress code word*）是用说的而不是输入的胁迫密码：一个事先约定、听起来很普通的词或句子，意思是“我不太好，但我没法明说”。偶然听到的人只会以为是闲聊。知道暗语的人则会听出这是求救，而且已经知道该怎么做。

常见的使用场合：

- **工作场所和安保团队。** 银行、商店、医院和安保人员常常约定一句话，可以当着施暴者的面通过电话或对讲机说出，让同事在无人察觉的情况下求助。
- **公共安全计划。** 在英国，许多酒吧和娱乐场所参与了“Ask for Angela”计划：在约会或夜间外出时感到不安全的人，向工作人员询问“Angela”，受过培训的工作人员就会悄悄提供帮助，比如帮忙叫出租车。这个暗语是有意公开的，方便场所张贴海报。其他国家也有类似的做法。
- **家人和朋友。** 有些家庭会约定一个词，让孩子或亲人在短信或电话里不用解释就能表达“来接我”或“帮我求助”。如今很多家庭还会约定一个*验证暗语*，用来确认一通惊慌失措的电话确实来自家人，而不是用 AI 克隆声音的骗子。这更像是验证用的词，而不是胁迫码，但同样的原则也适用。

有效暗语的*类型*示例（请自己编，不要照搬）：

- 询问一个并不存在的人，例如“今晚 Angela 上班吗？”；
- 问一个对方知道是错的问题，比如关于宠物、亲戚或家务；
- 在一句普通的话里加入一个不寻常的细节，比如你从不提起的颜色或菜名。

好的胁迫暗语在你会用到它的对话中听起来很自然，不会被无意中说出，配有事先约定的应对方式（谁联系谁、接下来做什么），并且时不时复习一下，以免有人忘记。请保密：发到网上的暗语，或者被你害怕的那个人知道的暗语，就不再起作用了。

## 手机上的胁迫 PIN：iPhone 和 Android 提供什么

搜索“手机胁迫码”“胁迫 PIN”或“胁迫指纹”的人，通常想知道自己的手机有没有内置这样的功能。简短的回答是：iPhone 没有，大多数 Android 手机也没有。

### iPhone

- **没有胁迫密码。** iOS 没有能打开诱饵内容、发出警报或抹掉手机的第二个密码。
- **SOS 紧急联络会停用面容 ID。** 同时按住侧边按钮和任一音量按钮约两秒，会出现关机和 SOS 紧急联络界面。<!-- TODO verify iOS label --> 此后在输入密码前，面容 ID 和触控 ID 都会保持停用，别人无法把手机举到你面前来解锁。如果不想拨打电话，轻点“取消”；视你的设置而定，继续按住可能会拨打紧急电话。详情见[有人逼你解锁手机时该怎么办](id:forced-to-unlock-phone)。
- **“抹掉数据”不是胁迫密码。** “设置”→“面容 ID 与密码”中的“抹掉数据”<!-- TODO verify iOS label -->会在连续 10 次输错密码后抹掉 iPhone。它能防止有人猜密码，但对站在你身边逼你说出密码的人没有用。
- **胁迫功能存在于 App 内部。** 由于 iOS 没有系统级的胁迫 PIN，iPhone 上的任何胁迫功能都属于某个 App，只能作用于该 App 的数据。下文介绍的 Velcrypt 胁迫图案就是一个例子。

### Android

- **锁定模式。** 在 Android 9 及以上版本中，许多手机的电源菜单里有“锁定”（Lockdown）选项；有些品牌需要先在设置中开启。<!-- TODO verify: Android label and Samsung One UI changes --> 它会锁定手机，并在输入 PIN、图案或密码之前停用指纹和人脸解锁。
- **标准 Android 没有胁迫 PIN。** Google、三星和大多数其他厂商出厂的 Android 都没有内置胁迫 PIN。<!-- TODO verify -->
- **GrapheneOS 的胁迫 PIN。** GrapheneOS 是一款面向受支持 Google Pixel 手机、注重安全的操作系统，提供胁迫 PIN 和胁迫密码。在手机要求输入凭据的任何地方输入其中之一，都会立即、不可逆地抹掉整台设备，包括 eSIM。这能保护数据，但事后很明显手机已被重置。
- **第三方 App。** 一些开源 Android App，例如 F-Droid 上的 Duress 和 Wasted，会监测锁屏界面是否输入了胁迫密码，然后锁定或抹掉手机，它们依靠无障碍和设备管理员权限实现。可靠程度取决于手机型号和 Android 版本。<!-- TODO verify -->

### “胁迫指纹”是什么意思

**胁迫指纹**（duress fingerprint）是指专门登记为无声警报的某一根手指。一些生物识别门禁系统支持这一功能：扫描这根手指时，门照常打开，同时向安保人员发送胁迫警报。主流手机不提供这一功能。<!-- TODO verify --> 在手机上，被胁迫时生物识别反而是弱点，因为别人可以把手机举到你面前，或者把你的手指按在传感器上。所以能迅速停用面容 ID 很重要，这也是 Velcrypt [刻意不提供面容 ID 解锁](id:pattern-lock-vs-pin-vs-face-id)的原因。

## 手机 App 如何实现胁迫码

手机上通常没有可以通知的监控中心，所以胁迫码转而保护数据。常见做法有：

1. **打开无害内容。** 胁迫码会打开一个诱饵：第二个看起来很普通的空间。这接近于[诱饵保险箱](id:what-is-a-decoy-vault)，单靠它不会删除任何东西。
2. **打开无害内容，并删除其余内容。** 胁迫码打开诱饵，同时清除敏感数据。这是最强的形式，而且无法撤销。
3. **清除一切。** 一些注重安全的系统提供会抹掉整台设备或整个 App 的胁迫 PIN。这能保护数据，但会让人明显看出发生了什么。

好的实现和差的实现之间的区别，主要在于**能被观察到什么**：

- 解锁的外观和耗时是否与正常解锁相同？
- 是否有任何设置、标记或文件会暴露设置了胁迫码？
- 之后屏幕上是否有任何变化？

只要其中任何一项会暴露胁迫码，就可能让紧张的局面变得更糟。

## Velcrypt 的胁迫图案如何运作

Velcrypt 通过在 5×5 点阵上画图案来解锁，每个图案都会打开各自的保险箱。它的[胁迫图案](id:duress-pattern)是建立在这一模式之上的 Premium 功能：

- **你需要在诱饵保险箱内设置它**，路径是“设置”→“胁迫图案”。诱饵保险箱是第二个保险箱，里面放着无害、可信的内容。第一个保险箱之外的保险箱需要 Premium。
- **你画两次一个独立的图案并确认。** 它不能是已经能打开某个保险箱的图案。
- **在解锁界面画出胁迫图案，会打开诱饵保险箱**，同时悄悄、永久地删除这部 iPhone 上的其他所有保险箱。
- **屏幕上不会显示发生了什么。** 解锁的外观和耗时与平常相同。
- **App 从不显示是否设置了胁迫图案。** iOS 钥匙串中始终存在一条固定大小的加密记录；未设置胁迫图案时，它存放的是随机字节。
- **每部 iPhone 只有一个。** 设置新的胁迫图案会替换旧的。关闭它需要画出它，而关闭不会删除任何内容。
- **Premium 到期后它仍然有效。** 只有设置时需要 Premium。

如果你在手机上唯一的保险箱中设置它，就没有其他可删除的内容，Velcrypt 会就此提醒你。

## 坦诚说明局限

### 删除是永久性的

被删除的保险箱无法在手机上恢复。保险箱数据不包含在 iCloud 和电脑备份中，所以唯一的恢复途径是你事先在“设置”→“备份”中创建的加密备份文件。备份是免费的，而保存在 App 之外的备份文件不会受到胁迫图案的影响。[安全页面](id:security#encrypted-backup)介绍了备份如何受到保护。

### 删除不等于物理擦除

闪存存储无法保证被删除的字节会立即被物理擦除。Velcrypt 依靠的是：保险箱数据使用 AES-256-GCM 加密，密钥会随保险箱目录一起删除，因此任何残留数据都只是没有密钥的密文。

### 它只作用于 Velcrypt 的保险箱

「照片」图库、「最近删除」、iCloud、聊天记录或别人手机里的副本都不会受到影响。[导入后请删除原始照片](id:delete-original-photos-after-import)。

### 它无法撤销旁观

如果有人看到或拍下了你画真正图案的过程，胁迫图案改变不了他们已经知道的事。

## 责任：胁迫密码不该用来做什么

胁迫密码是人身安全工具，适用于抢劫、威胁，或控制欲强的伴侣要求查看你手机这类时刻。

它**不是**销毁证据或规避警方、边境官员或法院合法要求的手段。各国法律不同，在法律要求下删除数据本身就可能构成违法，例如销毁证据或妨碍调查。如果你正面临或预计会面临法律要求，请寻求法律意见。出行相关内容，请参阅[过境时的手机隐私](id:phone-privacy-border-crossing)。

## 你应该使用它吗？

如果你能想象自己被逼着解锁保险箱，而且宁愿失去这些文件也不愿让人看到，胁迫图案就有意义。如果这些文件无可替代而你又没有备份，或者在压力下你很难记清哪个图案对应什么，它的意义就没那么大。

如果你决定使用，请先备份，再建立一个可信的诱饵保险箱，然后阅读[如何设置诱饵保险箱和胁迫图案](id:set-up-decoy-vault-and-duress-pattern)。如果你是因为某个具体的人而考虑它，[有人逼你解锁手机时该怎么办](id:forced-to-unlock-phone)介绍了更全面的安全应对。Premium 方案列在[价格页面](id:pricing)上。
