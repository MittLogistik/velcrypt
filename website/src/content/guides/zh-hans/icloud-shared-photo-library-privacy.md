iCloud 共享照片图库是 Apple 为家庭打造的贴心功能之一：旅行、生日、学校活动的照片集中在一个图库里，大家都可以往里添加。但它也可能让一张银行账单截图或一张私密照片，在你不知情的情况下出现在伴侣、父母或青春期孩子面前。本指南会讲清楚其他参与者到底能看到什么、能做什么，照片如何在你什么都没点的情况下进入共享图库，以及怎样把不想分享的照片留在外面。

## 什么是 iCloud 共享照片图库

共享图库是“照片”App 中与你的**个人图库**并列的第二个照片图库。根据 Apple 的说明，基本情况如下：

- 需要 iOS 16.1、iPadOS 16.1 或 macOS Ventura 及更高版本，并打开“iCloud 照片”。
- 最多可容纳 6 人：创建它的组织者，加上最多 5 位其他人。你一次只能加入一个共享图库。
- 所有内容都占用组织者的 iCloud 储存空间，不占用其他参与者的空间。
- 你添加一张照片时，它会从个人图库**移动**到共享图库，而不是拷贝。
- 创建共享图库不需要家人共享。未满 13 周岁（具体年龄因国家或地区而异）的用户，只能和自己“家人共享”群组的成员创建或加入共享图库。

## 其他参与者能看到什么、能做什么

这是大多数人低估的地方。共享图库对任何人都不是“只读”的：Apple 明确表示，所有参与者都可以添加、编辑和删除内容。

| 对共享图库中项目的操作 | 任何参与者 | 仅添加者 | 仅组织者 |
| --- | --- | --- | --- |
| 查看照片或视频，包括日期、位置和说明 | 可以 | | |
| 编辑、裁剪、收藏、修改说明或日期 | 可以，且所有人都会看到改动 | | |
| 删除（进入“最近删除”） | 可以 | | |
| 从“最近删除”中永久删除 | | 可以 | |
| 移回个人图库 | | 可以 | |
| 添加或移除参与者、删除共享图库 | | | 可以 |

共享图库中的内容还会出现在每个人的“回忆”、精选照片和“照片”小组件里。也就是说，你移进去的照片可能在别人没有刻意寻找的情况下，出现在对方的主屏幕上。

参与者**看不到**的是你的个人图库。如果伴侣在家里的 iPad 上看到了你的私密照片，原因通常是那台设备登录了你的 Apple 账户，而不是共享图库。这种情况请参阅[为什么你的照片会出现在家里的 iPad 上](id:family-shared-icloud)。

## 照片是如何进入共享图库的

一共有五条途径，只有第一条需要你有意识地逐张操作。

1. **手动移入。** 在“照片”中选择照片，轻点“更多”按钮（•••），然后选择**移至共享图库**。在设置过程中，也可以一次性批量移入以前的照片。
2. **相机的“共享图库”按钮。** 加入后，“相机”屏幕顶部会出现“共享图库”按钮。按钮打开时，新拍的照片和视频会直接存入共享图库；关闭时则存入个人图库。
3. **自动共享。** 选择此选项后，当你靠近其他参与者时，“相机”会自动把照片添加到共享图库。要检测参与者是否在附近，对方需要登录 Apple 账户并打开蓝牙。
4. **在家时共享。** 你在家拍摄的照片和视频会自动添加到共享图库。
5. **共享建议。** “照片”会推荐你可能想添加的照片，例如参与者在附近时拍的照片，或包含你在设置时选择的人物的照片，并发送通知提醒你查看。在你确认之前不会移动任何照片，但人们很容易不逐张检查就一次全部接受。

## 如何把私密照片留在共享图库之外

不必离开共享图库，也可以通过设置把它管好：

1. 前往**“设置”›“App”›“照片”›“共享图库”**（iOS 17 或更低版本为**“设置”›“照片”›“共享图库”**）。在“照片”App 中，也可以依次轻点“精选集”、右上角的账户和“共享图库”进入同一界面。
2. 轻点**“共享自相机”**。选择**“手动共享”**，这样只有在你自己打开按钮时，“相机”才会存入共享图库；也可以直接关闭“共享自相机”。同时确认**“在家时共享”**已关闭。
3. 如果不想再收到共享提醒，请关闭**“共享图库建议”**。
4. 拍私密照片之前，看一眼“相机”中的“共享图库”按钮，确认它处于关闭状态。
5. 检查已经共享的内容。把“照片”的图库视图切换为**“共享图库”**即可只看共享项目；在“两个图库”视图中，共享项目的缩略图角落会有一个小图标。这个视图选项的位置在不同 iOS 版本中有所变化；在 iOS 26 中，轻点“图库”，然后轻点“排序和筛选”按钮。

## 把照片移回个人图库

打开共享图库中的照片或视频，轻点“更多”按钮（•••），然后选择**“移至个人图库”**。也可以先选择多个项目。移回后，其他参与者就看不到它们了。

有两点限制需要注意。第一，你只能移动**自己**添加的项目；别人添加的你的照片会一直留在共享图库，直到对方移走或删除。第二，移回并不能抹去已经发生的事：照片共享期间，别人可能已经存储、用“信息”发送或导出了它。凡是进过共享图库的照片，都应当视为已经被看过。

## 隐藏的照片与共享图库

在共享图库中隐藏照片，并不能让它变成私密照片。根据 Apple 的说明，如果你隐藏共享图库中的照片，它会移到**所有参与者的**“已隐藏”相簿，其他人可以查看或取消隐藏。“已隐藏”相簿默认用面容 ID、触控 ID 或密码锁定，但每位参与者都是用自己的设备解锁，而不是用你的。

安全的顺序是：先把照片移至个人图库，再隐藏。另外请注意，个人图库中隐藏的照片仍会同步到所有登录你 Apple 账户的设备；详见[隐藏的照片会保存到 iCloud 吗？](id:are-hidden-photos-saved-to-icloud)

## 离开或删除共享图库

在“照片”中轻点“精选集”，再轻点右上角的账户，然后轻点**“管理”**：

- **“离开共享图库”**（参与者）：你可以选择把共享图库中的全部内容拷贝到个人图库，或只拷贝自己添加的内容。
- **“删除共享图库”**（仅组织者）：所有参与者都会收到通知。加入超过七天的人可以拷贝全部内容；加入不足七天的人只能拿到自己添加的内容。

组织者也可以单独移除某位参与者。但要注意：离开只能保护你以后的照片，保护不了以前的照片。其他参与者可以保留你分享过的所有内容的副本。

## 共享图库、共享相簿与家人共享的区别

这三个功能经常被混为一谈，但它们的运作方式完全不同。

| | iCloud 共享照片图库 | 共享相簿 | 家人共享 |
| --- | --- | --- | --- |
| 是什么 | 最多 6 人使用的第二个完整图库 | 与指定的人共享的单个相簿 | 共享购买项目、订阅和 iCloud+ 储存空间的群组 |
| 会自动共享照片吗 | 可能会，来自相机和在家时 | 不会，需要自己添加 | 不会 |
| 谁能编辑和删除 | 所有参与者 | 所有者；如允许，订阅者可以添加 | 不适用 |
| 开启高级数据保护后是否端到端加密 | 所有参与者都开启时是 | 否，始终不在范围内 | 每个人的个人图库遵循各自的设置 |

## 那加密呢？

“iCloud 照片”是加密的，但在默认的标准数据保护下，密钥由 Apple 保管。根据 Apple 的说明，开启高级数据保护后，共享内容只有在**所有参与者**都开启该功能期间才保持端到端加密；只要有一位家人没开，共享图库就会失去这层保护。共享相簿则完全不在保护范围内。如何开启以及需要注意什么，请看 [iCloud 高级数据保护详解](id:icloud-advanced-data-protection-explained)。

如果你在找“加密的家庭照片”方案，诚实的答案是：在 Apple 体系内最接近的，是一个所有参与者都开启了高级数据保护的共享图库。加密保护的是 Apple 服务器上的照片，对那五位本来就该看到这些照片的参与者毫无作用。

## 独立的加密保险箱适合什么场景

共享图库是为分享而设计的。对于绝不想分享的照片，更可靠的做法是把它们彻底移出“照片”图库。

Velcrypt 就是为此设计的 iPhone 保险箱 App。导入的照片、视频和文稿会在 iPhone 上用 AES-256-GCM 加密，通过在 5×5 网格上绘制的图案打开，而不是用设备密码或面容 ID。[没有账户、没有服务器、没有同步](id:offline-no-account)，保险箱数据也被排除在 iCloud 云备份和电脑备份之外，因此保险箱里的内容不可能出现在共享图库、共享相簿或家里的 iPad 上。每个图案打开各自独立的保险箱，你还可以准备一个被看到也无妨的诱饵保险箱。

导入会创建一份加密副本，原始照片仍然保留。导入后，请在“照片”中删除原始照片，并清空“最近删除”。如果照片原本在共享图库中，请先把它移至个人图库或在共享图库中删除；并记住，只有添加者才能从“最近删除”中将其永久删除。

诚实地说，也有取舍：保险箱不能用来分享，它只存在于你的 iPhone 上，忘记图案就无法恢复。为防手机丢失，请在“设置”→“备份”中创建加密备份文件，并保存在安全的地方。从保险箱导出照片，会重新生成一份普通的、未加密的副本。

## 快速检查清单

- 把“共享自相机”设为“手动共享”，或直接关闭。
- 如果不需要，关闭“在家时共享”和“共享图库建议”。
- 拍私密照片前，检查“相机”中的“共享图库”按钮。
- 用“移至个人图库”把私密项目移回，然后隐藏或放进保险箱。
- 照片还在共享图库里时，不要指望隐藏能保护它。
- 绝不能共享的内容，放在“照片”之外、设备上的加密保险箱里。
