Verrouiller une note dans Apple Notes est l’une des astuces de confidentialité les plus discrètes de l’iPhone. Vous glissez quelques photos ou un document numérisé dans une note, vous la verrouillez, et tout disparaît derrière votre code. C’est gratuit et intégré. Mais ce n’est pas vraiment une photothèque, et c’est là qu’un coffre dédié comme Velcrypt se distingue.

## Comment fonctionnent les notes verrouillées

Une note verrouillée est une note dont le contenu est chiffré et masqué jusqu’à ce que vous vous authentifiiez. Sur les versions récentes d’iOS, vous pouvez verrouiller vos notes avec le code de l’appareil, ou définir un mot de passe Notes distinct ; Face ID ou Touch ID peut être autorisé comme raccourci. Le titre de la note reste visible dans la liste, tandis que le contenu et les pièces jointes sont masqués. Si Notes est synchronisé avec iCloud, les notes verrouillées se synchronisent aussi sur vos autres appareils.

Vous pouvez ajouter des photos de votre photothèque, prendre une photo depuis la note ou numériser un document. Certains types de pièces jointes ne peuvent pas forcément être verrouillés, et les notes verrouillées ne peuvent pas être partagées de la manière habituelle. ## Là où les notes verrouillées fonctionnent bien

Si vous devez garder à l’abri des regards la copie d’un passeport scanné, quelques captures d’écran ou un courrier médical, une note verrouillée est rapide et fiable. Vous avez déjà l’app, elle se synchronise, et vous y accédez depuis votre Mac. Pour les documents en particulier, [numériser des documents en toute confidentialité](id:scan-documents-privately-iphone) compare les approches.

## Là où un coffre dédié aide

Notes est avant tout une app d’écriture. Dès que vous avez des dizaines ou des centaines d’images, ou des vidéos, faire défiler des notes devient laborieux. Velcrypt est organisé comme une app photo : des [albums](id:albums) dans chaque coffre, une visionneuse plein écran avec zoom et balayage, la sélection multiple, le déplacement d’éléments entre albums et l’import de documents depuis l’app Fichiers ([documents privés](id:private-documents)).

L’autre différence, c’est le secret. Si vous verrouillez vos notes avec le code de l’appareil, toute personne qui connaît ce code peut les ouvrir. Un mot de passe Notes distinct règle ce problème, mais il reste un seul mot de passe pour toutes les notes verrouillées. Le motif de Velcrypt est indépendant de votre code, et chaque motif ouvre un coffre séparé qui ne révèle pas les autres. Un motif que l’app n’a jamais vu ouvre un coffre vide : vous pouvez donc garder un leurre. Voir [verrouillage par motif](id:pattern-lock) et [coffres cachés](id:hidden-vaults).

## Quand Apple Notes peut mieux vous convenir

- **Vous n’avez que quelques éléments.** Une note verrouillée est plus simple que d’installer quoi que ce soit.
- **Vous voulez une synchronisation entre iPhone, iPad et Mac.** Velcrypt est réservé à l’iPhone et ne se synchronise pas.
- **Vous voulez pouvoir récupérer vos données.** Avec iCloud, vos notes verrouillées survivent à la perte du téléphone.
- **Vous aimez le confort de Face ID.** Velcrypt ne le propose volontairement pas.

## Quand Velcrypt peut mieux vous convenir

- **Vous avez une vraie collection.** De nombreuses photos, vidéos et documents, organisés en albums.
- **Vous ne voulez rien dans le cloud.** Les données des coffres restent sur le téléphone et hors des sauvegardes iCloud ; une sauvegarde chiffrée n’est créée que si vous le décidez.
- **Vous avez besoin d’espaces privés séparés.** Chaque motif est son propre coffre.
- **Quelqu’un d’autre connaît votre code.** Le motif est un secret distinct.

## Dans tous les cas, supprimez les originaux

Ajouter une photo à une note ou l’importer dans Velcrypt crée une copie ; l’original reste dans Photos. Supprimez-le et videz « Suppressions récentes », sinon il y reste environ 30 jours. Les étapes sont dans [supprimer les photos originales après l’import](id:delete-original-photos-after-import).
