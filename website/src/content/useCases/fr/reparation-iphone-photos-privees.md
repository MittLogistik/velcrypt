Un écran fissuré ou une batterie qui lâche à 40 %, c’est déjà assez stressant. Puis vient une pensée inconfortable : une personne que vous n’avez jamais vue va tenir un appareil qui contient toute votre vie. Un peu de préparation rend la remise bien plus sereine.

## Ce à quoi un technicien pourrait réellement accéder

La plupart des réparateurs sont des professionnels qui n’ont aucun intérêt pour vos photos. Il est quand même utile de savoir ce qui est possible :

- **Avec votre code :** tout. Photos, l’album « Masqués » (il se déverrouille avec le code depuis iOS 16), Fichiers, Mail, Messages et les notes verrouillées avec le code de l’appareil. Voir [l’album « Masqués » est-il privé ?](id:is-iphone-hidden-album-private)
- **Sans votre code :** très peu de choses sur un iPhone verrouillé et en état de marche. iOS chiffre les données de l’utilisateur et les lie à votre code : les fichiers sont illisibles sans déverrouillage.
- **Pendant les diagnostics :** certaines réparations exigent que le téléphone démarre et exécute des tests. Le réparateur peut demander votre code pour vérifier que la réparation fonctionne.
- **Si l’appareil est remplacé ou effacé :** vos données ne reviennent que depuis une sauvegarde.

## Avant de le confier

1. **Faites une sauvegarde complète.** Utilisez la sauvegarde iCloud ou une sauvegarde sur ordinateur. Vérifiez qu’elle s’est bien terminée.
2. **Suivez les consignes du réparateur concernant Localiser.** Les versions récentes d’iOS prennent en charge un état de réparation qui permet à l’appareil de rester associé à Localiser pendant l’intervention, alors qu’auparavant on vous demandait de le désactiver. Demandez à votre réparateur ce qui s’applique, ou consultez l’[assistance Apple](https://support.apple.com/).
3. **Demandez si votre code est vraiment nécessaire.** Beaucoup de réparations matérielles n’en ont pas besoin.
4. **Mettez les éléments sensibles hors de portée.** Scans de pièces d’identité, photos médicales et photos intimes ne devraient pas rester dans la photothèque pendant une réparation.
5. **Déconnectez-vous de ce qu’on ne doit surtout pas ouvrir,** comme les apps bancaires ou professionnelles, si le réparateur a besoin du code.
6. **Gardez un moyen de vous connecter ailleurs.** Si vos codes de double authentification arrivent sur ce téléphone, assurez-vous d’avoir un autre appareil de confiance ou des codes de récupération pendant son absence.

## Après l’avoir récupéré

- Changez le code de votre appareil si vous l’avez communiqué.
- Ouvrez Réglages › Confidentialité et sécurité › Contrôle de sécurité (iOS 16 et ultérieur) pour vérifier quels appareils et quelles apps ont accès à vos données.
- Vérifiez que Localiser est activé et que votre compte Apple n’affiche que vos appareils.

## Comment Velcrypt vous aide

Velcrypt conserve photos, vidéos et documents dans des coffres chiffrés sur votre iPhone. Le coffre ne s’ouvre ni avec le code de votre appareil ni avec Face ID : il faut le [schéma que vous tracez sur une grille 5×5](id:pattern-lock). Même si un technicien a votre code et ouvre Velcrypt, tracer autre chose que votre schéma affiche simplement un coffre vide — aucune erreur, aucun indice que d’autres coffres existent.

Les photos importées sont des copies : pensez à [supprimer les originaux](id:delete-original-photos-after-import) et à vider « Suppressions récentes » avant la réparation. Sinon, elles sont toujours dans Photos.

## La contrepartie honnête : les sauvegardes

Voici ce qu’il faut peser avec soin. Dans la première version, les données des coffres Velcrypt sont **exclues des sauvegardes iCloud et sur ordinateur**. C’est volontaire — rien ne quitte votre appareil —, mais cela signifie que :

- Si la réparation se termine par un iPhone effacé ou remplacé, votre coffre ne peut pas être restauré, ni par vous ni par Velcrypt.
- Une option de sauvegarde et de récupération chiffrées est prévue, mais pas encore disponible.

Pour tout ce qui est irremplaçable, gardez donc une seconde copie dans un endroit de confiance avant la réparation — par exemple sur un disque chiffré que vous contrôlez. Il en va de même si vous [oubliez votre schéma](id:forgot-vault-pattern). Pour en savoir plus sur ces choix de conception, consultez la [page sécurité](id:security).

## Autres limites à garder en tête

- Les copies de photos dans Photos iCloud, Messages ou les e-mails ne sont pas protégées par un coffre. Vérifiez [si les photos masquées se synchronisent avec iCloud](id:are-hidden-photos-saved-to-icloud).
- L’icône Velcrypt est visible sur l’écran d’accueil, sauf si vous utilisez l’option d’iOS 18 pour masquer des apps.
- Aucune app ne protège contre un logiciel malveillant sur un appareil jailbreaké ou modifié. Si vous soupçonnez une manipulation après une réparation, faites vérifier le téléphone par Apple ou un réparateur agréé.

Une réparation ne devrait pas vous obliger à tout confier à un inconnu. Sauvegardez, sortez les éléments sensibles des endroits évidents, et vous pourrez remettre votre téléphone l’esprit tranquille.
