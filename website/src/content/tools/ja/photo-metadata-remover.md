## 仕組み

写真を選ぶと、ブラウザがあなたの端末から直接ファイルを読み込みます。ツールはJPEGファイルの中のEXIFブロックを探し、特に多くを明かしてしまう項目をわかりやすく表示します。カメラのメーカーと機種、レンズ、撮影日時、最後に編集したソフトウェア、向き、そして地図を使わず緯度と経度だけで示すGPS座標です。

**メタデータを削除**をタップすると、ツールは画像のピクセルをキャンバスに描き、向きを反映した真新しいJPEGとして保存します。ピクセルだけから作られた新しいファイルには元のファイルに埋め込まれていたデータが一切含まれないため、EXIF、GPS、XMP、IPTC、そのほかのメタデータは消えます。

これらはすべてページの中で行われます。写真がアップロードされることはなく、ページを離れたあとに何かが残ることもありません。

## EXIFデータとは

EXIF（Exchangeable Image File Format）とは、写真に関する情報を画像ファイルそのものの中に保存するための規格です。カメラアプリは撮影のたびに自動で書き込みます。日付や場所でライブラリを整理するのに便利ですが、写真をファイルとして共有すると、一緒に相手に渡ります。

iPhoneでは、1枚の写真に次のような情報が含まれることがあります。

- **位置情報：** カメラの位置情報サービスがオンなら、正確なGPS座標。
- **日時：** 撮影された日時（秒単位まで）。
- **デバイス：** iPhoneの機種と、使われたレンズ。
- **ソフトウェア：** 最後に保存したiOSのバージョンや編集アプリ。
- **向き：** 表示するときに画像をどう回転させるか。

## 何がわかってしまうか

いちばん大きいのは位置情報です。自宅で撮った写真を元のファイルのまま共有すると、住所がわかってしまうことがあります。一定期間の写真が集まれば、生活パターンが見えてしまうこともあります。GPSがなくても、機種や日時から複数の写真を同じ人物に結びつけられる場合があります。

多くのSNSやメッセージアプリはアップロード時に一部のメタデータを削除しますが、その挙動はさまざまで、書類として送る、メールで送る、クラウドのリンクで送るといった方法では、そのまま残ることがよくあります。元のファイルにはすべてが含まれていると考えておくのが最も安全です。そもそも誰がアクセスできるのかは、[写真にアクセスできるアプリの確認方法](id:which-apps-can-see-your-photos-iphone)で説明しています。

## iPhoneでツールを使う

1. このページをSafariで開きます。
2. 選択ボタンをタップし、写真ライブラリか「ファイル」から写真を選びます。
3. 項目を確認します。GPSに座標が表示されたら、その写真には位置情報が含まれています。
4. **メタデータを削除**をタップし、クリーンなコピーを保存します。
5. 元の写真ではなく、クリーンなコピーを共有します。

Safariで写真を選ぶとiOSがHEICをJPEGに変換することがあるため、ツールが受け取るファイルはライブラリ内のものと少し異なる場合があります。共有シートで位置情報をオフにするなど、標準機能での方法は[iPhoneで写真のメタデータを削除する方法](id:remove-photo-metadata-iphone)をお読みください。

## プライバシー

このツールはブラウザの中だけで動作します。アップロードの工程も、アカウントも、画像を受け取るサーバーもありません。これはVelcrypt自体と同じ原則、つまりプライベートなデータは端末の中にとどめるべきだという考えに基づいています。[オフライン・アカウント不要](id:offline-no-account)をご覧ください。

## 制限事項

- **すでに共有したコピー：** ツールが消去できるのは、渡されたファイルだけです。すでに送信、投稿、バックアップしたコピーにはメタデータが残ります。
- **写っている内容：** 顔、番地、道路標識、窓からの景色、映り込みから、誰なのか、どこなのかがわかることがあります。
- **形式：** JPEG、PNG、WebPは最新のブラウザならどれでも使えます。HEICはSafariなど、ブラウザが開ける場合のみです。
- **再エンコード：** クリーンなコピーは新しいJPEGなので、ファイルサイズや圧縮が少し変わることがあります。
- **表示内容：** 詳しい項目表示はJPEGファイルのEXIFが対象です。ほかの形式では表示される項目が少なくなることがありますが、クリーンなコピーからはそのメタデータも削除されます。

写真そのものが機密性の高いものなら、メタデータの削除は対策の一部にすぎません。残りは[プライベートな写真を安全に保管する方法](id:store-intimate-photos-safely-iphone)で説明しています。写真をどうロックして保管するかを考えるには、[パターン強度チェッカー](id:pattern-strength-checker)も役立ちます。
