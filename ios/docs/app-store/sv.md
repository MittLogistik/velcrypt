## Description (1,517/4,000)

```
Velcrypt är ett privat valv för bilder, videor och dokument som ingen annan ska se. Allt krypteras på din iPhone med AES-256-GCM. Inget konto. Inget moln.

ETT MÖNSTER, ETT VALV
Du låser upp Velcrypt genom att rita ett mönster på ett rutnät med 5×5 punkter. Varje mönster öppnar ett eget, separat valv och Velcrypt visar aldrig en lista över valv. Ett okänt mönster öppnar bara ett tomt valv: inget felmeddelande och ingen antydan om att något mer finns.

HA ETT SKENVALV
Fyll ett andra valv med harmlösa bilder. Om någon pressar dig att öppna appen ritar du det mönstret. Ett nödmönster för tvångssituationer kommer snart.

KRYPTERAT PÅ DIN IPHONE
• AES-256-GCM-kryptering för varje bild, video och dokument
• Ditt mönster blir nyckeln direkt på enheten. Ingen annan har en kopia, inte ens vi.
• Inget konto, ingen registrering, inget moln
• Valvdata undantas från säkerhetskopior till iCloud och dator

DITT MÖNSTER, INTE DITT ANSIKTE
Velcrypt använder medvetet varken pinkod eller Face ID. Nyckeln finns i ditt huvud.

ORDNING
• Importera från Bilder eller Filer
• Album i varje valv
• Sök på namn och album
• Rutnät eller lista, ljust eller mörkt tema
• Automatisk låsning

BRA ATT VETA
• Ett glömt mönster kan inte återställas. Utan det går valvet aldrig att öppna igen.
• Import skapar en kopia. Originalen finns kvar i Bilder eller Filer tills du raderar dem där.
• Valven säkerhetskopieras inte. Om du tappar bort eller återställer din iPhone förlorar du även valven.

Velcrypt. Well Encrypted. Truly Private.
```
