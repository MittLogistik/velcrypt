## Description (1,303/4,000)

```
Velcryptは、誰にも見られたくない写真、ビデオ、書類、メモのためのプライベートな保管庫です。すべてiPhone上でAES-256-GCMにより暗号化されます。アカウント不要、クラウドなし、トラッキングなし。

1つのパターンに1つの保管庫
5×5のドットにパターンを描いてロックを解除します。パターンごとに別々の保管庫が開き、Velcryptが保管庫の一覧を表示することはありません。知らないパターンを描くと空の保管庫が開くだけで、エラーも、ほかの保管庫の存在を示すものもありません。

ダミーの保管庫(プレミアム)
2つ目の保管庫に当たり障りのない写真を入れておけば、アプリを開くよう迫られたときにそちらを見せられます。

iPhone上で暗号化
・すべての写真、ビデオ、書類、メモをAES-256-GCMで暗号化
・パターンはデバイス上で暗号鍵に変換されます。そのコピーはほかの誰も持っていません。私たちも持っていません。
・アカウント登録なし、クラウドなし、広告なし、トラッキングなし
・保管庫のデータはiCloudやコンピュータのバックアップから除外

顔ではなく、パターンで
VelcryptはあえてPINやFace IDを使いません。鍵はあなたの頭の中にあります。

すべてを1か所に
・「写真」や「ファイル」から読み込み
・保管庫内カメラ:撮影した写真やビデオは写真ライブラリを経由せず、直接保管庫に保存
・コード、パスワード、個人的なメモを残せるセキュアなメモ
・アルバム、検索、グリッド/リスト表示
・ライト/ダークテーマ、自動ロック

暗号化バックアップ
保管庫を、自分で決めたパスワードで保護された1つの暗号化ファイルにバックアップできます。iCloud Driveやコンピュータに保存しておけば、新しいiPhoneで復元できます。

アプリを偽装(プレミアム)
ホーム画面のアイコンを、計算機、タイマー、定規などに変更できます。

Velcrypt Premium
無料版では、保管庫1つに最大50件まで保存できます。プレミアムでは、項目数無制限、複数の保管庫、別のAppアイコンが使えます。
```
