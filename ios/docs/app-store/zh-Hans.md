## Description (651/4,000)

```
Velcrypt 是一个私密保险库，用来存放你不想让任何人看到的照片、视频和文稿。所有内容都在你的 iPhone 上使用 AES-256-GCM 加密。无需账户，不用云端。

一个图案，一个保险库
在 5×5 的点阵上绘制图案即可解锁 Velcrypt。每个图案都会打开一个独立的保险库，Velcrypt 从不显示保险库列表。未知的图案只会打开一个空的保险库：不会报错，也不会透露还有其他内容。

伪装保险库
在第二个保险库中放一些无关紧要的照片。如果有人逼你打开 App，就绘制那个图案。胁迫图案功能即将推出。

在 iPhone 上加密
• 每张照片、每个视频和文稿都使用 AES-256-GCM 加密
• 你的图案在设备上直接转换为密钥。其他任何人都没有副本，包括我们。
• 无需账户，无需注册，不用云端
• 保险库数据不包含在 iCloud 或电脑备份中

用图案，而不是面容
Velcrypt 刻意不使用 PIN 码和面容 ID。密钥只在你的脑海里。

整理
• 从“照片”或“文件”导入
• 每个保险库都可以创建相簿
• 按名称和相簿搜索
• 网格或列表视图，浅色或深色主题
• 自动锁定

请注意
• 忘记的图案无法恢复。没有它，该保险库将永远无法再打开。
• 导入是拷贝。原件会保留在“照片”或“文件”中，直到你在那里删除。
• 保险库不会被备份，因此如果丢失或还原 iPhone，保险库也会随之丢失。

Velcrypt. Well Encrypted. Truly Private.
```
